## 1. 收斂方向：把課程地圖變成「可以帶走的探索」

核心概念：**先看見四年，再發現一門課；願意收藏的人，再把自己的選擇連成星座。**

主要任務是認識、搜尋及理解課程；收藏與星座是可跳過的創作體驗。不收藏、不登入、不命名也能完成全部找課與閱讀流程。

視覺是安靜的夜空，資訊是清楚的人文筆記。使用者不只看網站提供的圖，也能創造一份具有自己名字的探索作品。

| 目前問題 | 新設計的解法 | 判斷是否改善 |
| --- | --- | --- |
| 有些課看起來沒有分類 | 探索訊號與正式作用分開；65 門有主訊號、4 門明確標為整合匯流 | 每門課都能找到，沒有空白或「其他」垃圾桶 |
| 展開後地圖太長 | 四年總覽 → 單一年級／學期星圖；詳情放旁邊或抽屜 | 開啟課程不新增整段縱向地圖，不需捲過多個展開區 |
| 操作中規中矩 | 對焦 → 收星 → 連線命名；操作產生個人作品 | 使用者能理解自己選了什麼，完成可編輯、可帶走的結果 |

不採用強制興趣測驗、解鎖關卡、假成就、常駐粒子特效，也不把星座解讀為能力／人格評量。驚喜來自「資訊因我的選擇而改變」與「我真的做出一個作品」。

## 2. 既有規格的延續與有意變更

### 保留的事實

- 69 門課：必修 15、選修 54；資料列學分合計 138，**不是使用者畢業所需或已修學分**。
- 正式作用：基底 20、應用 45、整合 4。
- 正式課程基本資料、作用、面向與模組已有核定狀態；不重新要求原資料審核、不改寫原分類。
- 課程簡介、活動、成果依目前資料仍屬草案，正式前台沿用既有核定欄位顯示規則：未核定內容不公開，顯示「課程詳細說明整理中」。若內部原型需展示草案，必須明示且不得當作正式發布內容。
- 個人連線只表示探索意圖，不表示先修關係、修課承諾、學程認證或能力達成。

### 相對於 PRD v1.2 的有意變更

原先未納入節點地圖、收藏與本機儲存；依使用者最新方向，本提案新增星圖、個人探索收藏、星座創作及自願本機保存。這是新版本的產品範圍，不宣稱它們原本就符合舊版全部排除項目。

本提案不新增帳號、雲端同步、社群發布、學校選課或正式成績資料。分享只可在後續使用可驗證的網址／下載檔案，不假設有短網址服務或後端。

## 3. 資訊架構與第一次進站

入口只用一段話：

> 看見四年的課程安排，找到你想進一步了解的課。

主行動「開始探索」；次行動「直接看所有課程」。不需要先答題或先選訊號。

第一次進入可用一句非阻擋提示：「點選課程查看內容，也可以收藏感興趣的課程。」四訊號旁說明：「選擇你感興趣的方向，看看哪些課程相關。」不以強制導覽擋住地圖。

主要只有三個工作模式：

1. **探索星圖**：四年總覽與學期星圖；找課與閱讀即可完成主要任務，收藏為次要操作。
2. **我的星座**：低強度的選用入口；從收藏中選代表星、調整位置、命名與下載。不作必經步驟。
3. **所有課程**：同一份 69 門資料的搜尋清單，作為快速查找及可及性替代。

既有課程結構說明、圖例、四年摘要等重複內容收斂為工作台的短說明與「課程怎麼安排？」補充入口，不再把每種圖都垂直堆在主頁。

## 4. 主要畫面：一張有邊界的探索工作台

### 桌面配置

```text
├───────────────────────────────────────────────────────────┤
│ 探索訊號  文本思辨  敘事創作  數位媒介  文化現場   清除   │
├─────────────────────────────────┬─────────────────────────┤
│ 四年總覽 / 大二                 │ 課程筆記                │
│ 大一  大二  大三  大四   上／下  │ 完整課名                │
│                                 │ 年級／學期／必選修      │
│      ●     ○                    │ 學分／正式作用與面向    │
│   ○             ●               │ 主／次探索訊號          │
│           ◇            ○        │ 課程內容／草案標示      │
│                                 │ ＋ 收藏課程             │
│ 大二上：11 門；訊號相關：X 門   │                         │
└─────────────────────────────────┴─────────────────────────┘
```

此示意圖是已收藏的情境；收藏摘要合併至既有工具列，不新增會推動畫面的行。未收藏時不顯示收藏摘要、空匣或進度提示。一般課程星圖不預畫看似先修或官方路線的連線。

收藏摘要實作放入既有頁首／工具列的次要位置，窄螢幕顯示精簡入口，不新增會把星圖向下推的底部區塊。已有收藏可還原摘要，但不自動開啟星座。

- 寬螢幕右側筆記約 320–380 px；星圖使用其餘空間。中等寬度改用可收合詳情，不硬擠兩欄。
- 四年總覽呈現四個星群入口，分別標「大一 12 門、大二 23 門、大三 23 門、大四 11 門」。星群輪廓是示意，不是進度條或能力雷達。
- 總覽不塞入 69 個可點擊小點與 69 個課名；點年級進入真正課程節點。
- 年級內依「上／下學期」顯示，每次最多 12 門；切換學期是明確按鈕，不要求左右拖曳。
- 節點有可讀課名，長課名至多兩行、對焦後顯示全名。節點與文字一起構成可點選區，不靠小星點命中。
- 不預設大一全是基底；星圖使用實際課程作用與資料。

- 手機每組最多約 6 個有標籤節點；用上一組／下一組切換，不把桌面星圖縮成無法點擊的小點。
- 詳情採底部抽屜，帶可見關閉鈕；手指上滑可擴展但不是必要操作。抽屜內容可捲動，返回時保留原星圖頁次。
- 螢幕很短、虛擬鍵盤開啟、文字放大 200% 時改為正常文件流／清單，不裁掉按鈕。
- 星圖可用 `dvh` 調整，桌面參考高度 480–640 px、手機 320–440 px，**不是不可突破的固定高度**；資訊優先於填滿畫面。
- 不鎖住整頁捲動；只有開啟 modal 抽屜時管理背景捲動。沒有多個互相競爭的地圖捲動區。
- 手機的收藏摘要同樣只在有收藏時出現於既有工具列；建立星座的完整文案放在收藏面板，避免窄螢幕擠滿操作。

## 5. 四個探索訊號：少量入口，完整覆蓋

| 訊號 | 使用者想做的事 | 主訊號門數 |
| --- | --- | ---: |
| 文本思辨 | 讀懂文字、語言與思想 | 20 |
| 敘事創作 | 把觀察和想法說成故事 | 14 |
| 數位媒介 | 讓人文與科技產生連結 | 10 |
| 文化現場 | 走進地方、文化與社會 | 21 |
| 整合匯流，非第五訊號 | 把不同探索帶入專題／實習 | 4 |

這是新增導航草案；完整逐門歸類、理由與需核對項目在 [分類文件](EXPLORATION_SIGNALS_v1.md)。例如「人文地理學概論」是基底課，同時以文化現場為探索入口；不再讓「基底」看起來像沒有方向。

### 顯示規則

- 訊號是**高亮透鏡**，不是把其他課刪掉的硬篩選。年級、學期與手機頁次決定當下有哪些節點；訊號改變高亮與相關門數。
- 支援複選，使用 OR：主訊號或次訊號符合任一選取項即相關，同一課程只計一次。
- 主色常駐；次訊號只在鍵盤對焦、點選或詳情顯示。50 門有次訊號，不因此產生 50 個永久雙色光圈。
- 沒有選訊號時，所有課程等強度可讀；有選訊號時，非相關課稍降背景強度，但文字與控制項仍可讀、可操作。
- 四門整合課在對應學期保留「整合匯流」標籤與位置：人文創新設計專題、實務實習、畢業專題製作(一)、畢業專題製作(二)。不假裝它們符合所有訊號。
- 數量文案分開顯示，如「本學期 12 門｜相關 X 門｜整合 1 門」；匯流不灌入每個訊號相關數。
- 點「清除訊號」只清訊號；不改年級、學期、搜尋結果或收藏。
- 搜尋涵蓋全 69 門，不被當前訊號限制。開啟搜尋結果時定位正確年級／學期／頁次，保留訊號並說明匹配狀態，不讓搜尋命中的課再次消失。
- 若要只看相關課，以清單模式明示「僅顯示相關」，不在星圖偷偷換成另一套可見性規則。

## 6. 視覺系統：夜空探索 × 紙頁筆記

保留現有深綠、暖紙、珊瑚、青綠、金色語彙，補一個低飽和藍紫。避免把整站全部做成半透明玻璃。

| 用途 | 建議色 | 規則 |
| --- | --- | --- |
| 星圖背景 | `#102630` | 深綠藍，少量靜態星點，不干擾節點 |
| 課程筆記／表面 | `#f6f0e4` | 暖紙色，長文閱讀區 |
| 文本思辨 | `#b8bde9` | 藍紫 |
| 敘事創作 | `#eea08b` | 珊瑚 |
| 數位媒介 | `#83d6cd` | 青綠 |
| 文化現場 | `#e9c579` | 金色 |
| 選取／鍵盤焦點 | 暖白雙層輪廓＋圖示／文字 | 不再借某個訊號顏色當通用選取色 |

以上是原型起始值，正式上線前量測對比；不宣稱尚未測量的全部組合都合格。暖紙上的彩色文字改用同色系深色，不直接沿用夜空用色。

- 標題：有編輯感的繁體中文襯線字；操作與內文：清晰無襯線字。優先既有字體／系統字體，若需新字型先檢查授權、檔案量及載入失敗。
- 內文約 16 px，圖上課名 14–16 px，行高 1.5–1.7。年份可大，操作說明不要縮成低對比 10 px。
- 作用採「基底空心圓、應用實心圓、整合菱形」並同時提供文字／可及名稱；顏色只表達探索訊號。
- 必修有獨立「必修」標示；星星大小不代表課程比較重要、比較難或比較適合某人。
- 深色區以線條／留白分層，紙色詳情以排版分層，陰影與發光各自節制。
- 不使用自訂游標、滑鼠尾跡或全站滾動視差。星點背景靜態；只有操作中的相關元素移動。

### 按鈕與回饋層級（2026-10-09 補充）

- 基本控制保持熟悉的按鈕形態。單一任務區只突出一個主要操作；收藏不是找課畫面的最高強度行動。
- 統一文案：「查看課程」「＋ 收藏課程」「✓ 已收藏」「取消收藏」「查看收藏」「用收藏課程建立我的星座」。收星、航行等詞只用於敘事與動畫，不取代操作文字。
- 定義 normal、hover、focus-visible、pressed、selected、disabled；loading／success／error 僅在真實非同步操作時使用，不為本機收藏假設等待狀態。
- 年級／學期採一致的單選按鈕群，探索訊號採複選切換按鈕；選中同時有輪廓與標記。使用原生 button 與合適的 aria-pressed，勿混用不完整的 tabs 語意。
- 一般按壓約 100–150 ms，可小幅下壓；不移動點擊區、不讓整段文字縮放。focus 不靠 hover 才可見。
- 「收藏課程／已收藏」使用穩定寬度；字體、圖示、收藏摘要的更新不改變星圖及控制列位置。
- 動效三層：日常操作輕回應、場景轉換交代位置、創作完成才有短暫驚喜。不得使用催促收藏的跳動／閃爍按鈕。
- 所有操作先更新資料與文字；動畫可中斷、可反向，新操作接續目前狀態。不播放排隊動畫，不用動畫時間鎖住按鈕。

## 7. 三個值得記住的操作

時間是原型起始值，需實際操作後調整。動畫描繪已提交的狀態，不延遲資料更新、不等待動畫完成才允許下一個動作。

### A. 對焦一顆星：從課名走進課程筆記

- **觸發**：點節點／按 Enter 或 Space；hover 只作輕提示，不自動換掉詳情。
- **回饋**：節點出現暖白輪廓，完整課名顯示；其他節點減少裝飾亮度，位置不因對焦而跳動。
- **成功**：旁邊筆記顯示同一門課，年級／學期／必選修／學分／作用與正式面向穩定可見。探索主次訊號另列。
- **取消／反向**：關閉筆記、Esc 或網站返回恢復原位置；開啟另一課可立即切換，不排動畫佇列。
- **鍵盤／觸控**：每一節點可 focus；手機直接 tap。桌面非 modal 側欄不強制搶焦點，提供「閱讀課程筆記」入口；手機 modal 開啟後焦點移入並管理 Tab。
- **減少動效**：直接換內容＋靜態輪廓，不縮放、不滑行。
- **一般節奏**：輪廓 100–140 ms、筆記交接 180–240 ms；全程保持文字清楚。

### B. 收星：把「我有興趣」變成可見的累積

- **觸發**：課程筆記中的「＋ 收藏課程」。第一版以按鈕為主；拖入收藏只列為後續候選，不擴大節點點按與手勢的衝突。
- **回饋**：收藏狀態立即改成「✓ 已收藏」；小星沿短路徑移到工具列的收藏摘要，約 220–320 ms，收藏清單出現同一課名。第一筆先同步建立摘要目的地，再量測；無可用目的地時只顯示文字回饋。
- **成功**：以 course ID 去重；相同課無法收藏兩次；計數與匣清單同一時間更新。
- **取消／反向**：再點「取消收藏」或在匣移除，提供「復原」；拖出目標外或按 Esc 取消，不提交。
- **鍵盤／觸控**：按鈕完成完全相同結果；手機不要求拖曳。僅拖曳把手攔截手勢，不妨礙普通滑動。
- **減少動效**：取消飛行，只顯示已收藏與簡短 live region 通知。
- **異常**：快速連點、飛行途中取消或切頁，以最後的資料狀態為準；動畫中止，不留下幽靈星。通知不反覆打斷讀屏。

### C. 編成星座：讓選擇成為自己的作品

- **觸發**：「用收藏課程建立我的星座」；至少收藏一門即可開始，沒有測驗或四年收齊條件。無收藏時主動進入「我的星座」，只給「先收藏感興趣的課程」與返回找課入口，不彈提醒、不自動導航。
- **回饋**：先帶入已收藏課程的代表星，依年級／學期作初始排列；兩顆以上畫出個人連線。
- **成功**：星座能命名、替換代表星、調整位置、刪除／復原、下載。結果明示「我的探索星座」。
- **取消／反向**：回探索時保留本次工作階段草稿；刪星或替換可復原。清空所有資料需明確確認。
- **鍵盤／觸控**：代表星可以清單勾選／替換；位置可拖曳，也可用「移動」模式與方向按鈕調整；Esc 退出移動模式，Enter 完成。
- **減少動效**：立即顯示連線與名稱，不播放畫線或發光。
- **完成節奏**：第一次命名完成，連線短暫描出約 400–600 ms，再回靜態。改名不重播慶祝，不放滿頁煙火。

### 切換年級／學期的輔助契約

點按明確年份／學期按鈕 → 新節點立即可讀，短淡入提示場景已換 → 控制項與計數同步 → 可隨時切回，網站返回恢復前一狀態 → 鍵盤按鈕與手機 tap 同等 → reduced-motion 直接換場景。切換不清空收藏；快速跨年份操作由最新一次接手。

## 8. 個人星座如何保持美麗，又不限制探索

採用兩層但清楚命名的資料：

- **我的探索**：想進一步了解的課程收藏，可保留全部 69 門，以緊湊清單管理。它不是正式選課清單。
- **星座代表星**：從收藏中挑最多 **8 門**呈現在作品上。8 是第一版的構圖上限提案，不是學程規定或必須達到的目標；後續依原型可讀性調整。

第一版只提供一份可編輯星座，不急著加入多個星座、資料夾或作品牆。收藏超過八門時不阻止收藏；首次建星座暫以收藏順序前八門帶入，明示「代表星 8／8，探索收藏共 N 門」，允許替換。第九顆代表星不偷偷淘汰舊星，改開「替換一顆代表星」。

代表星上限、替換與構圖規則只在主動建立／編輯星座時揭露；一般瀏覽與收藏不展示「還差幾顆」或八格空位。進站、搜尋、切學期都不自動進入星座。

- 年級／學期只是初始排序。正式年級仍在課名旁，拖曳圖形不會改寫課程年份。
- v1 以時間排序作固定連線順序，無箭頭；同學期以 ID 穩定排序。自由拖曳只改構圖，不自動創造新先修關係。
- 作品角落說明：「連線是你的探索想像，不是課程先修順序。」
- 每顆代表星顯示課名及年份，收藏清單可看完整資料；一顆也能命名，兩顆才有連線。
- 刪除代表星只移出作品，不刪收藏；從收藏移除已入作品的課，說明並同步移除代表星，提供一次復原。
- 更換探索訊號不改變星座。整合課若映照周圍星色，僅作構圖，不宣稱其正式涵蓋所有訊號。

### 實際課程的示例

使用者可以收藏「文本分析與詮釋」「創意文案寫作」「報導文學與非虛構寫作」「出版編輯與地方刊物」，再加入「互動敘事與遊戲企劃」，把作品命名為 **「讓地方開口」**。

這會形成從文本理解、書寫到出版與互動媒介的個人探索組合。這是展示玩法的使用者選擇示例，不是官方推薦修課路線，也不根據課名推論保證的學習成果。

## 9. 保存、命名與分享邊界

### v1 必做：自願本機保存＋SVG 下載

- 未同意保存前，收藏與星座只在目前頁面的記憶體；僅在收藏面板／星座編輯器清楚標「尚未儲存，重新整理會清除」。未收藏的一般瀏覽者不看到此提醒，也不寫入個人資料。
- 主行動「儲存在這台裝置」；由此開啟本機保存。顯示「僅限此瀏覽器／此裝置，不是雲端備份」，後續變更自動保存並顯示實際結果。
- `localStorage` 讀寫需處理被停用、容量／格式／版本錯誤；保存失敗時保留記憶體草稿、說明失敗，仍可下載。不能顯示假成功。
- 存檔帶 schema version；未知課程 ID 不渲染、不污染原資料，提示略過並保留有效內容。
- 命名作純文字，去頭尾空白，建議上限 24 個可見字元（grapheme），支援中文輸入法組字。空白可回到「未命名星座」，不因此禁止保存。
- SVG 包含名稱、課名、年份、連線與探索聲明；以安全序列化轉義文字，不插入使用者 HTML、不依賴遠端素材。檔名使用安全預設值，下載後實際開啟核對長課名與繁體字。
- 名稱只存在本機與使用者下載的檔案中；不是網站公開發表。SVG 是第一版出口，PNG 視匯出驗證結果列入後續。

### 後續候選：分享網址

網址可帶版本、有效 course IDs、代表星與有界正規化座標；預設不放自由命名文字。不製作沒有後端支援的假短網址。

接收者先看「收到的探索星座」，不得自動覆蓋自己的收藏／本機星座；按「另存到我的星座」時若已有作品需確認取代。解析需驗證長度、ID、座標與版本，無效內容可安全返回普通探索。實作時再驗證既有 URL 與新分享格式的相容性。

## 10. 元件與資料方案

優先沿用既有前端框架、課程資料、學期整理及既有課程網址／歷史行為。以下是**建議元件邊界**，不是宣稱目前已有這些元件。

| 元件 | 責任 |
| --- | --- |
| ExplorationWorkbench | 模式切換與布局，不保存第二份課程資料 |
| SignalControls | 四訊號、清除、選取狀態與相關數 |
| YearOverview／CourseStarMap | 總覽、學期、頁次、確定性座標與節點 focus |
| CourseInspector | 正式課程事實、草案標示、收藏操作 |
| ExplorationTray | 收藏摘要、完整收藏清單及復原 |
| ConstellationEditor | 代表星、構圖、名稱、本機保存、SVG 出口 |
| CourseListView | 所有課程的可搜尋替代入口 |

- 新增的探索映射預計放 `src/data/explorationSignals.json`，以穩定 ID 連結原資料，含 `primary/secondary/signalPolicy/status`；本輪未建立此程式檔。
- 原 `primaryTrack/relatedTracks/role/verification` 不被新訊號覆寫；新訊號全部由 draft 起步，確認後再更新新映射狀態。
- 狀態至少區分 `selectedSignals`、`year/semester/page`、`activeCourseId`、`collectedIds`、`representativeIds`、`positions`、`name`、`persistenceEnabled`。
- 收藏 ID 集合是唯一來源；代表星必須是其子集且不重複。計數衍生而來，不另存容易失真的累計值。
- 布局採確定性模板，避免每次刷新亂跳。星圖裝飾與連線可用 SVG；課程互動優先可及的 DOM 按鈕，不用重型 WebGL 才能完成。
- 節點在視覺與 DOM 的讀取順序一致；鍵盤主要採正常 Tab／按鈕操作，不先加入陌生的方向鍵圖形導航規則。
- 路由保存前後瀏覽語意；既有網址參數若表示正式面向，不可直接改解釋成新訊號。新導覽使用有版本／新名稱的參數。
- 動效不持有業務狀態；返回、視窗縮放、手機旋轉、長字體載入、快速操作時重新定位，保持選擇不丟失。

## 11. 分階段實作，不一次重寫整站

| 階段 | 可審閱交付 | 該階段的驗收 |
| --- | --- | --- |
| 1. 可操作設計切片 | 真實課程＋大一／大二星圖＋詳情，桌面與手機；不依賴收藏 | 長課名、12 節點密度、聚焦／返回及 reduced-motion 流程 |
| 2. 完整探索 | 全 69 門、四年／八學期、四訊號與清單替代 | 覆蓋／統計一致、搜索跨學期、整合定位、頁面不被詳情拉長 |
| 3. 選用收藏與個人星座 | 收藏清單、最多 8 代表星、可編構圖、命名 | 空收藏不打擾、收藏不推動畫面；替換／移除／復原、拖曳取消、鍵盤與觸控完成相同作品 |
| 4. 帶走作品 | 自願本機保存與 SVG 匯出 | 重載恢復、保存失敗、字串安全、下載檔實際開啟 |
| 5. 可選擴充 | PNG／分享網址；有需求才加 | 匯出字體／長課名、接收者草稿保護及網址相容 |

先用一個真實可操作切片驗證星圖是否值得，再擴展到全站。分享與多星座管理不阻擋核心上線。

詳細順序與完成條件以 [UI 修訂與逐項開發任務](UI_IMPLEMENTATION_TASKS_v1.md) 的 UI-01～UI-19 為準，與原專案 TASKS_v1.md 的 T01～T21 分開管理。

- [ ] 檢查約 1440、1024、768、390、360 px，以及低高度螢幕；長課名不撞、不被截掉。

- [ ] normal／hover／focus-visible／pressed／selected 等按鈕狀態一致；狀態文案改變不改變尺寸，動畫可被新操作中斷。
- [ ] 點擊區至少達 WCAG 2.2 AA 24 CSS px（包含允許間距例外），手機主要操作目標以 44 px 為設計目標。
