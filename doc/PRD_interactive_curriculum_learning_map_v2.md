## 1. 產品摘要

本產品是一張可互動的四年課程與學習地圖，不是完整學系網站、正式選課系統或性向測驗。

地圖以「文學文化為基底，其他都是應用與轉譯」為核心結構，協助學生理解：

1. 四年會學什麼。
2. 能逐步培養什麼能力。
3. 在課程中可能做出什麼成果。
4. 文學文化與人文方法如何延伸至寫作創作、數位人文、文化與社會實踐。
5. 必修主幹與選修空間如何共同構成個人的學習組合。

產品的一句話說明：

> 從文學文化與人文方法奠基，探索寫作、數位與文化實踐，看看四年會學什麼、培養什麼能力、做出什麼成果。

## 2. 問題定義

現有正式課程清單可以回答「有哪些課」，但難以讓初次接觸學系的學生理解：

- 課程之間有什麼關係。
- 文學文化基礎為何重要。
- 能力如何由大一逐步累積至大四。
- 課堂會進行哪些學習活動。
- 課程可能產出哪些具體成果。
- 選修如何與個人興趣形成不同組合。

若只呈現課名，學生容易將學系理解成課程目錄；若只強調數位、AI、策展或文創，又會讓文學文化基底消失，造成對實際課程結構的誤解。

因此，本產品需要把正式課程轉化為可閱讀的四年學習進程，而不是重新發明一套脫離課程事實的推薦系統。

### 2.1 目前證據狀態

- 大學部正式規劃清單共69門課：15門必修、54門選修。
- 課名、年級、學期、學分與必選修以正式課程清單為準。
- 能力標註、課程作用、典型活動及可能產出尚須由系所或授課教師核定。
- 既有高中生觀點主要來自設計假設，尚不能視為真實使用者研究結論。
- 正式清單15門必修共30學分；整併計畫書另載「人文思維與方法」核心26學分，兩者關係須於發布前確認。

## 3. 產品目標與非目標

### 3.1 主要目標

使用者完成一次地圖探索後，應能：

1. 說明本系以文學文化與人文方法為共同基底。
2. 說出四個年級主要在學什麼、練習什麼、可能完成什麼。
3. 分辨必修主幹與選修探索空間。
4. 看見一項核心能力如何跨年級累積。
5. 找到符合興趣的課程，並理解它與基底課程及成果的關係。
6. 理解三個應用面向不是招生分組、固定分流或正式修課建議。

### 3.2 非目標

第一版不處理：

- 完整學系介紹、系所沿革、師資與研究成果。
- 入學管道、招生FAQ或獨立家長專區。
- 完整職涯配對、薪資資訊或就業承諾。
- 正式選課、課表安排、衝堂檢查與學分試算。
- 畢業資格或先修條件自動判定。
- 人格、性向、適系程度或職業測驗。
- 固定分流或自動產生個人修課建議。
- 使用者帳號、登入及個人資料蒐集。
- 教師課程管理後台。

相關資訊如有需要，只提供一個明確的系所官方網站外部連結。

## 4. 使用者與使用情境

### 4.1 主要使用者

高中二、三年級學生，包含：

- 對文學、文化、寫作或社會議題有興趣者。
- 對數位內容、AI、影像、遊戲、策展或地方文化有興趣者。
- 尚未確定方向，希望先理解四年學習內容者。
- 想知道人文課程如何轉化為實作成果者。

網站不可假設使用者已理解「跨域人文」「數位人文」「文化轉譯」或課程模組等術語。

### 4.2 次要使用者

- 在校生：可查詢完整課程與理解能力關係，但本產品不是選課工具。
- 家長、教師與輔導教師：可透過同一張地圖理解課程結構，不另設專區。
- 系所行政與教師：負責核定、更新與維持資料可信度。

### 4.3 核心使用情境

1. 快速了解四年學習進程。
2. 依年級與學期查找課程。
3. 依面向探索相關課程。
4. 切換能力檢視，理解能力累積。
5. 查看課程活動、產出與實際案例。
6. 參考示例路徑，理解課程可以如何組合。
7. 收藏或分享目前的探索結果，與教師、家長或同學討論。

## 5. 課程地圖核心模型

### 5.1 三層學習結構

#### 第一層：文學文化基底

所有應用與轉譯的共同基礎，包括：

- 文本閱讀與詮釋
- 文學與文化理解
- 語言、敘事與表達
- 田野調查與研究方法
- 批判思考與文化判讀

此層包含大部分大一、大二必修，以及文學、文化、語言、哲學與研究方法相關選修。

**重要：「作用」與「必選修」是兩個獨立屬性。** 必修不等於全是基底課：必修中的「數位人文方法與應用」、「數位策展：理論與實務」屬於應用；「人文創新設計專題」、「實務實習」、「畢業專題製作(一)、(二)」屬於整合。因此不可將「必修主幹」直接等同於「基底層」。

#### 第二層：應用與轉譯

以三個探索面向呈現，不代表固定分流：

1. **寫作與創作**：散文、小說、詩歌、報導、文案、出版與文化內容創作。
2. **數位人文與內容**：數位敘事、資料分析、AI協作、空間人文、互動企劃與數位策展。
3. **文化與社會實踐**：地方創生、田野、品牌、節慶、策展、文化資產與社會議題。

同一門課可以同時連結多個面向，但應標示一個主要面向，避免分類失去辨識力。若面向內需要更細分類，以面向下的次標籤處理（例如數位人文與內容下再分「AI 與資料」與「互動與敘事」），不另設獨立控制。

本系不設「語文教育」探索面向，也不作首頁主敘事。清單中偏教學／語言學的課程（如漢語詞彙與教學、漢字文化與教學、漢語語言學與教學實務、語言與文化等）仍完整保留於四年檢視與完整課程清單，其 `primaryTrack` 可為空（`null`），只是不歸入任一探索面向。

#### 第三層：整合與成果

透過專題、實習、策展與畢業製作，整合前述基底與應用能力，形成可展示、討論或持續發展的成果。

### 5.2 四年學習主線

> **探索與奠基 → 方法與轉譯 → 跨域實作 → 整合與展現**

| 年級 | 學什麼 | 主要能力發展 | 可能做什麼 |
|---|---|---|---|
| 大一 | 人文、地理、文本、文化與數位方法 | 閱讀、理解、分析、表達、初步工具運用 | 文本分析、文化觀察、初步數位練習 |
| 大二 | 田野、質性研究、議題設計、敘事及各類選修 | 訪談、研究、敘事、資料整理與文化轉譯 | 田野紀錄、訪談資料、議題分析、故事企劃 |
| 大三 | 專題、文化研究、數位策展、實習及進階選修 | 協作、企劃、策展、媒介應用與場域實作 | 數位內容、創作作品、展覽企劃、文化方案、實習成果 |
| 大四 | 畢業專題、文化事業與成果整合 | 綜合運用、專案完成、展演與公開表達 | 畢業專題、作品集、成果展演或文化提案 |

上述能力與產出為地圖層級摘要，仍須經系所核定，不取代單門課程綱要。

## 6. 核心能力架構

地圖採固定能力詞彙，避免每門課自由命名後無法比較。

| 能力 | 定義 |
|---|---|
| 文本閱讀與詮釋 | 理解、分析並說明不同類型文本的內容、形式與意義 |
| 文學文化理解與脈絡分析 | 將作品、文化現象與歷史、社會及地方脈絡連結 |
| 田野調查與研究方法 | 進行觀察、訪談、資料蒐集、整理、分析及研究倫理判斷 |
| 敘事表達與文化轉譯 | 將知識、文化或議題轉化為適合不同受眾與媒介的內容 |
| 數位工具與媒介應用 | 運用數位工具、資料方法、AI或互動媒介支援人文工作 |
| 企劃協作與實作整合 | 定義問題、形成方案、協作執行並完成可檢視的成果 |

### 6.1 能力作用層級

- **奠基：** 初次建立概念、方法或基本練習。
- **發展：** 在較複雜的問題或任務中反覆運用。
- **整合：** 綜合多項能力，獨立或協作完成成果。

層級代表課程提供的學習機會，不表示每位學生修完後必然達到相同程度。

### 6.2 標註規則

- 每門課最多標示2項主要能力、2項次要能力。
- 每項主要能力需標示奠基／發展／整合之一。
- 能力與層級必須由系所或授課教師核定。
- 地圖提供「依能力檢視」，顯示能力跨年級的相關課程，不計算能力分數。

每門課的產出資料分為：

1. **可能產出：** 經教師確認的典型作業或成果形式。
2. **實際案例：** 前身學系或本系課程中已完成、取得授權且可公開的作品。

因新課程與前身學系課程**非一對一對應**，凡來自前身學系的作品須明確標註為「**前身學系相近課程作品**」，不得直接掛在新課名下，以免讓人誤以為「修這門新課就會做出此作品」。

不得把假想產出描述成每年固定要求，也不得只展示少數高度精緻成果而造成普遍性誤解。

## 8. 主要功能需求

### 8.1 四年地圖

- 顯示大一至大四四個階段。
- 每個年級先顯示「學什麼／獲得什麼／做什麼」摘要。
- 顯示必修主幹，選修預設收合。
- 可依上學期、下學期或全年查看。
- 手機採垂直展開，不要求橫向拖曳才能理解四年進程。

### 8.2 結構檢視

三種檢視是**同一份課程清單的不同分組方式**，不另做版面、不隱藏正式課程、也不產生另一份課程資料：

- **四年檢視：** 依年級、學期分組（預設）。
- **基底與應用檢視：** 依作用（基底／應用／整合）分組，組內再依年級排序。
- **能力檢視：** 選定一項能力後，依年級列出相關課程並標示作用層級。

手機版面：

- 三種檢視共用同一組可垂直展開的課程卡，只改變分組標題與排序，不改變卡片樣式。
- 基底與應用檢視：以「基底／應用／整合」三個可收合區塊呈現，區塊標題固定可見。
- 能力檢視：頂部先出現單選的能力選單，選定後下方依年級列出課程並以標籤標示奠基／發展／整合。

### 8.3 面向探索（單一控制）

v2.0 原本同時有「興趣」與「應用面向」兩套機制，兩者講的幾乎是同一件事，會使資料標註加倍且優先順序不明。v2.1 合併為**單一「面向探索」控制**。

面向選項（可多選）：

- 文學文化基底
- 寫作與創作
- 數位人文與內容
- 文化與社會實踐

若需要更細的區分，使用面向下的**次標籤**，不另設控制。建議初版次標籤：

| 面向 | 次標籤（選用） |
|---|---|
| 數位人文與內容 | AI 與資料、互動與敘事 |
| 文化與社會實踐 | 地方與田野、策展品牌與文化企劃 |

規則：

- 預設不選，顯示完整地圖。
- 可選一個或多個面向，不設完成門檻。
- 選取後強調符合任一所選面向（或其次標籤）的課程。
- 非符合課程仍可讀、可操作；必修主幹始終清楚可見。
- 顯示所選摘要、相關課程數與「清除面向」。
- 面向與課程的對應由系所核定，不以課名關鍵字自動推定。
- 不使用「你適合」「推薦你」「最佳路徑」等判定語言。
- 介面標示應使用白話：「應用與轉譯」輔以白話說明（例如「把讀到、學到的東西做成作品」），不預設學生懂「轉譯」一詞。

### 8.4 示例路徑

示例路徑在使用者選定面向後，以「看一個四年範例」的方式出現，不與其他控制並列。第一版提供少量人工核定的四年組合示例，且**至少一條為跨面向組合**，以直接展示面向可以自由組合、並非分流：

1. 文學文化＋寫作與創作
2. 文學文化＋數位人文與內容
3. 文學文化＋寫作與創作＋數位人文與內容（跨面向示例）

每條路徑均須顯示：

> 本路徑僅用於理解課程如何組合，不是固定分流、正式選課建議或畢業資格規劃；且僅涵蓋系訂學分的一部分，照此修課不代表即可畢業。

示例路徑只引用正式課程，不保證課程於特定學期開設。

### 8.5 我的探索清單

- 使用者可收藏課程。
- 清單依年級與學期整理。
- 可由清單返回原課程位置。
- 清除面向不清空收藏。
- 清空收藏與清除面向為不同操作。
- 第一版預設僅保留於當次瀏覽；是否使用localStorage由校方決定。

### 8.6 分享探索結果

- 使用網址參數保存目前的面向選擇、檢視模式及示例路徑。
- 分享網址不得包含姓名、裝置識別資訊或其他個人資料。
- 收到分享網址後，使用者仍可清除條件並返回完整地圖。
- 收藏課程是否納入網址須經原型測試；若網址過長，第一版可不分享收藏。

### 8.7 官方資訊連結

頁尾只提供一個清楚標示的系所官方網站連結，供使用者查閱招生、師資、系所沿革與其他非課程地圖資訊。

## 9. 資訊架構與閱讀順序

## 10. 使用者流程

### 流程A：理解四年學習

進入地圖 → 閱讀四年摘要 → 展開年級 → 查看必修與選修 → 開啟課程詳情。

### 流程B：依面向探索

進入地圖 → 選擇一個或多個面向（可用次標籤細分）→ 查看被強調的課程 → 理解相關能力與產出 → 收藏課程。

### 流程C：查看能力累積

切換能力檢視 → 選擇一項核心能力 → 查看大一至大四相關課程與作用層級 → 開啟詳情。

### 流程D：參考示例路徑

選擇示例路徑 → 查看跨四年的課程組合 → 開啟任一課程 → 返回後保留路徑與位置。

### 流程E：分享討論

設定面向或檢視模式 → 複製分享連結 → 接收者開啟相同狀態 → 可自行修改或清除。

## 11. 響應式、操作與無障礙規格

### 11.1 手機

- 先顯示四年摘要，再依年級垂直展開課程。
- 允許多個年級同時展開以便比較。
- 面向與檢視控制可收合，但須保留已選摘要。
- 詳情採底部面板或全螢幕對話框，提供可見關閉按鈕。
- 不以橫向縮放或水平拖曳作為理解地圖的必要操作。

### 11.2 平板與桌機

- 平板依可讀性採兩欄或垂直排列。
- 桌機空間足夠時可採四年欄位，但不得壓縮文字至難以閱讀。
- 詳情可使用側邊面板。

### 11.3 共通操作

- 課程詳情不超過兩次操作即可抵達。
- 關閉詳情恢復原捲動位置，鍵盤焦點回到觸發課程卡。
- 面板開啟時焦點限制於面板，支援Escape關閉。
- 不依賴懸停；主要觸控區至少44×44 CSS像素。
- 所有功能均可使用鍵盤完成，並具可見焦點。
- 顏色之外提供文字或圖示標籤。
- 非強調課程仍維持可讀對比。
- 尊重減少動態效果設定。
- 分享狀態、錨點跳轉與詳情開關不得破壞瀏覽器返回行為。
- **返回鍵（瀏覽歷史）規則：** 切換面向、檢視、學期或篩選時，僅以 `replaceState` 更新網址，不新增瀏覽紀錄；只有開啟課程詳情時以 `pushState` 新增一筆。如此在手機上按返回鍵會先關閉詳情回到地圖，而非逐一倒退每一次篩選操作。

```json
    {

    "basic": "approved",
    "role": "approved",
    "track": "draft",
    "competencies": "draft",

```

欄位說明：

- `module`：計畫書正式模組（人文思維與方法、數位人文、文化創意與社會設計、文學創作）。**介面不顯示**，僅供日後與計畫書對照及系所評鑑。原計畫書「文學創作與語文教育」模組在本產品中記為「文學創作」。
- `primaryTrack`：主要探索面向，不歸入任一面向者可為 `null`（如偏教學／語言學課程）。
- `subTags`：面向下的次標籤，取代原 `interests` 欄位。
- `verification`：**每個欄位各自記錄核定狀態**（`approved`／`draft`），取代整門課單一 `verified` 開關。

範例中的分類、能力、活動及產出僅示範資料結構，未核定前不得視為正式課程說明。

### 12.1 資料規則

- 課程ID須穩定，不以課名作唯一識別。
- 年級與學期以正式課程清單為準。
- 課程資料保留適用學年度、最後核定日期及核定者角色。
- **欄位分級發布**（詳見 §16）：某欄位 `verification` 非 `approved` 時，該欄位不得以事實呈現，可顯示「說明整理中」；不因單一欄位未核定而隱藏整門課的 A 級基本資料。
- 允許由內容維護者預填草稿（`draft`）、再由系所或教師核定為 `approved`；此流程不屬於「自動標註」。
- 實際作品另以案例ID管理，並記錄對應課程、是否為前身學系相近課程作品、授權狀態與撤回狀態。

## 13. 內容治理

### 13.1 權責

- **系所課程負責單位：** 核定課名、學期、學分、必選修及開課說明。
- **授課教師／課程委員會：** 核定能力、作用層級、活動、產出及課程關聯。
- **內容維護者：** 更新JSON、版本日期、實際案例與連結。
- **資訊單位：** 管理部署、HTTPS、備份、復原與資安要求。

### 13.2 更新週期

- 每學年度正式課程確認後至少全面檢查一次。
- 課程異動、停開或名稱調整時同步更新。
- 網站清楚顯示資料適用學年度及更新日期。
- 規劃課程不等於當學期實際開課；未串接課務系統前，一律顯示「實際開課依當年度課表」。

### 13.3 作品與授權

- 公開學生作品、姓名、照片或訪談前取得明確授權。
- 記錄授權範圍、期限及撤回方式。
- 撤回後應能移除案例，不影響課程主資料。
- 不得將生成式AI製作的示意作品冒充學生真實成果。

## 16. 內容核定分級與分階段發布

第一版不進行使用者測試。最大風險在內容核定的工作量，尤其 115 學年新課多數尚未開過、無課綱，大三大四選修的「典型活動」與「可能產出」只能由教師推估，且 54 門選修牽涉多位（含兼任）教師。為避免核定卡住上線，採**欄位分級發布**，取代整門課單一核定開關。

### 16.1 欄位分級

| 層級 | 欄位 | 核定方式 | 上線條件 |
|---|---|---|---|
| A | 課名、年級學期、學分、必選修 | 以正式課程清單為準 | 直接發布 |
| B | 基底／應用／整合作用、主要面向 | 課程委員會開一次會一併核定 | 第一階段 |
| C | 能力與層級、典型活動、可能產出 | 授課教師核定 | 先做 15 門必修與示例路徑用到的選修；其餘顯示「說明整理中」 |

對應資料結構的 `verification` 物件（§12），每欄位各自標記 `approved`／`draft`。

### 16.2 分階段上線

- **第一階段：** 四年骨架、必修詳情、作用（基底／應用／整合）與面向（A＋B 級，必修與示例路徑相關選修的 C 級）。
- **第二階段：** 補齊其餘選修的能力、活動與產出（其餘 C 級）。

### 16.3 核定責任與流程

- 允許內容維護者預填草稿，再由系所或授課教師核定；此預填不屬於「自動標註」，但未核定前一律標為 `draft`、不得以事實呈現。
- 指定一位最終內容負責人，避免多版本衝突。
- 在校生可協助檢查課程分類與用語是否符合實際理解（非正式測試、不蒐集個資）；在校生排課需求不納入第一版。

## 17. 驗收標準

### 17.1 內容正確性

- 69門課程均可追溯至正式課程清單。
- 「地方創生與數位敘事」正確標示為一下。
- 課名、年級、學期、學分及必選修皆經核定。
- 必修30學分與計畫書核心26學分的關係已釐清並正確說明。
- 能力、層級、活動、產出與示例路徑均經系所核定。
- 未核定資訊不在正式環境顯示為事實。

### 17.2 理解設計檢核（不進行使用者測試）

第一版不做使用者測試，故以**介面與內容的設計檢核**取代任務成功率，由內容負責人逐項檢查：

- 地圖以白話呈現「文學文化課與應用課的關係」，不要求讀者理解或複述「轉譯」等專有名詞；「應用與轉譯」均附白話標籤。
- 可依指定年級、學期找到必修與選修課程，必修與選修在視覺上可清楚分辨。
- 每個年級均有「學什麼／獲得什麼／做什麼」的白話摘要。
- 能力檢視可沿一項能力列出跨年級課程並標示作用層級。
- 課程詳情能看到典型活動與可能產出，且未核定欄位顯示「說明整理中」而非臆測內容。
- 面向探索與示例路徑的頁面皆明確標示「非固定分流、非正式選課建議」。

### 17.3 互動與無障礙

- 手機不需橫向縮放即可完成主要任務。
- 課程詳情可明確開啟、關閉並返回原位置。
- 面向、能力、收藏與年級展開狀態互不誤清除。
- 鍵盤可完成所有主要操作，焦點順序與返回位置正確。
- 顏色不是唯一辨識方式，文字對比符合校方採用的無障礙標準。
- 分享網址能重建相同探索狀態，且不包含個資。

## 18. 風險與因應

| 風險 | 影響 | 因應方式 |
|---|---|---|
| 應用敘事壓過文學文化基底 | 與實際課程及系所定位不符 | 主圖固定呈現共同基底與向上轉譯關係 |
| 69門課同時展開造成資訊過載 | 高中生無法理解主線 | 必修先顯示、選修收合、漸進揭露 |
| 能力標籤由產品端主觀推定 | 形成新的錯誤資訊 | 由教師或課程委員會核定後發布 |
| 可能產出被誤解為保證成果 | 造成期待落差 | 清楚區分可能產出與實際案例 |
| 示例路徑被視為正式分流 | 限制學生理解或造成誤選 | 固定揭露用途與限制，不使用推薦語言 |
| 課程規劃與實際開課不同 | 降低可信度 | 顯示適用學年度及「依當年度課表」 |
| 能力架構過度複雜 | 地圖變成評量系統 | 只做六項能力與三層作用，不計分 |
| 在校生要求排課功能 | 產品範圍擴張 | 明定在校生可參考但非選課工具 |
| 作品授權不完整 | 權利與隱私風險 | 建立授權、撤回及案例移除流程 |

## 20. 最終產品原則

1. **先呈現學習結構，再提供自由探索。**
2. **文學文化是基底，應用與轉譯由此向外生長。**
3. **課程、能力與產出必須互相連結。**
4. **完整資料不等於一次顯示所有資訊。**
5. **提供可能組合，不替學生做適性判斷。**
6. **能力標註代表學習機會，不是能力保證。**
7. **所有內容均須回到正式資料與核定責任。**

使用者完成探索後，應能形成以下理解：

> 我知道這四年會如何從文學文化與人文方法開始，逐步練習寫作、數位與文化實踐；我也看得見自己可能培養的能力、完成的成果，以及可以如何組合課程。
