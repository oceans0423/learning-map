## 1. 產品摘要

本產品是一個面向高中生的「互動式四年課程與學習地圖」。它不是完整學系網站，也不是選課、排課或能力評量系統。

產品需要讓使用者在短時間內理解：

1. 四年各階段主要學什麼。
2. 文學文化與人文方法如何形成共同基礎。
3. 課程如何延伸至三個應用探索面向。
4. 哪些課程屬於必修、選修，以及安排在哪個年級與學期。
5. 專題、實習與畢業製作如何整合四年的學習。

核心敘事：

> 從文學文化與人文方法出發，透過敘事創作、數位媒介及文化社會實踐，把所學轉化為作品、企劃與行動。

## 2. 產品目標

### 2.1 核心目標

- 讓高中生不必理解系所術語，也能看懂四年學習進程。
- 將69門規劃課程整理成容易閱讀、探索與比較的課程地圖。
- 清楚呈現共同基底、應用探索及整合成果之間的關係。
- 以精緻視覺與必要互動建立可信、具辨識度的招生溝通介面。
- 支援手機、平板與桌機，且手機不需橫向拖曳才能理解內容。

### 2.2 非目標

第一版不處理：

- 正式選課、排課與衝堂檢查。
- 學分試算、畢業資格及先修判定。
- 人格測驗、適系測驗或自動推薦。
- 能力分數與學習成效評量。
- 使用者帳號、登入及跨裝置同步。
- 收藏清單、Cookie或個人追蹤。
- 完整學系沿革、師資、職涯、招生FAQ或家長專區。
- 大量學生作品與案例管理。

### 3.1 主要使用者

對人文、文化、寫作、數位內容或社會實踐有興趣的高中二、三年級學生。

## 4. 核心課程模型

### 4.1 三層學習結構

#### 第一層：共同基底

以文學文化與人文方法為共同基礎，涵蓋文本閱讀、文化理解、敘事表達、田野調查、研究方法及批判思考。

共同基底不是第四個應用面向，也不等於所有必修課。必修／選修與課程作用是兩個獨立屬性。

#### 第二層：應用探索

課程可連結一個或多個探索面向，三個面向不代表招生分組、固定分流或正式選課建議。

1. **敘事與創作**  
   包含散文、小說、詩歌、報導、文案、出版及跨媒介敘事。

2. **數位人文與媒介**  
   包含數位敘事、資料方法、AI協作、互動媒介、空間人文及數位策展。

3. **文化與社會實踐**  
   包含地方創生、田野調查、文化資產、策展、品牌、節慶及社會議題實作。

語文教育相關課程仍出現在完整課程地圖中；若無適合的主要面向，可以不設定面向。

#### 第三層：整合成果

透過專題、實習、策展、企劃及畢業製作，整合共同基底與不同面向的學習。

### 4.2 四年學習主線

> 探索與奠基 → 方法與表達 → 跨域實作 → 整合與展現

| 年級 | 學習重點 | 可能進行的學習活動 |
|---|---|---|
| 大一 | 建立人文、文本、文化與數位方法基礎 | 閱讀分析、文化觀察、基礎表達與數位練習 |
| 大二 | 學習田野、研究、敘事及議題分析方法 | 訪談、資料整理、故事企劃與議題分析 |
| 大三 | 進入專題、策展、實習及進階選修 | 數位內容、創作、文化方案、策展與場域實作 |
| 大四 | 統整所學並完成公開成果 | 畢業專題、作品集、成果展演或文化提案 |

上述摘要用於說明整體學習進程，不取代正式課程綱要。

## 6. 核心互動需求

互動只服務一個目的：協助使用者理解課程及其在四年學習中的位置。

### 6.1 年級展開

- 提供大一至大四四個階段。
- 每個階段先顯示「學什麼／如何學／可能完成什麼」摘要。
- 使用者可展開該年級的課程。
- 桌機可四年並列或分段呈現；手機採垂直手風琴。
- 必修優先顯示，選修可收合，避免69門課一次全部展開。

### 6.2 學期切換

- 提供「全年／上學期／下學期」。
- 預設為全年。
- 切換只調整課程顯示，不改變整體頁面結構。
- 若課程為全年或學期尚未確認，應有明確標示。

### 6.3 探索面向篩選

提供三個可複選的面向按鈕：

- 敘事與創作
- 數位人文與媒介
- 文化與社會實踐

互動規則：

- 未選擇時顯示完整課程地圖。
- 選擇後加強顯示符合任一面向的課程。
- 其他課程降低視覺強度，但不完全消失。
- 共同基底及必修主幹持續可見。
- 顯示目前條件及符合的課程數。
- 提供固定、清楚的「清除條件」。
- 不使用「推薦你」「你最適合」等判定語言。

### 6.4 結構視覺連動

頁面上方的「共同基底 → 應用探索 → 整合成果」結構可操作：

- 點擊共同基底，突出相關基礎課程。
- 點擊探索面向，套用相應面向篩選。
- 點擊整合成果，突出專題、實習、策展及畢業製作等課程。
- 所有狀態變化須同時透過文字、標籤或邊框表達，不只依賴顏色。

### 6.5 課程詳情

課程卡第一層顯示：

- 課程名稱。
- 年級與學期。
- 學分。
- 必修／選修。
- 課程作用或探索面向標籤。

點擊後以側邊抽屜、對話框或頁內展開方式顯示：

- 簡短課程說明。
- 課程在四年學習中的作用。
- 相關探索面向。
- 已有可靠資料時，顯示典型活動或可能產出。
- 「實際開課依當學年度課表」提醒。

關閉詳情後，須返回原本的捲動位置與篩選狀態。

### 6.6 網址狀態

- 網址可記錄年級、學期、面向及已開啟課程。
- 重新整理或分享網址後，可重建相同檢視狀態。
- 更新篩選條件時使用取代歷史紀錄的方式，避免手機返回鍵逐一倒退每次篩選。
- 開啟課程詳情時可新增瀏覽紀錄，使返回鍵能關閉詳情。
- 網址不得包含姓名、裝置識別資訊或其他個人資料。

## 7. 視覺與操作原則

### 7.1 視覺方向

- 整體感受應具人文氣質、當代感與學術可信度，避免制式校務系統風格。
- 年級是主要閱讀軸，探索面向是輔助辨識軸。
- 共同基底、應用探索與整合成果應有清楚層次，但不可讓使用者誤認為固定分流。
- 課程卡維持簡潔；詳細內容在使用者主動開啟後呈現。
- 避免將69門課做成必須縮放、拖曳或辨認大量連線的節點圖。

### 7.2 響應式

- 手機：單欄垂直閱讀、年級手風琴、篩選控制可收合或固定於易操作位置。
- 平板：一至二欄布局，保留清楚的年級順序。
- 桌機：可使用四欄或寬版時間軸，但不得犧牲文字可讀性。

### 7.3 動效

- 展開、篩選與詳情切換使用輕量動畫協助理解狀態變化。
- 動效不應延遲主要操作。
- 尊重系統的減少動態效果設定。

### 7.4 無障礙

- 所有主要功能可用鍵盤完成。
- 焦點樣式清楚，開關詳情後焦點回到原課程卡。
- 顏色不是唯一辨識方式。
- 文字及互動元件對比符合校方採用的無障礙標準。
- 按鈕、篩選狀態及展開狀態具正確的語意標記。

## 8. 課程資料規格

### 8.1 第一版必要欄位

```json
{
  "id": "course-example-01",
  "name": "地方創生與數位敘事",
  "year": 1,
  "semester": 2,
  "credits": 2,
  "type": "elective",
  "role": "application",
  "primaryTrack": "文化與社會實踐",
  "relatedTracks": ["數位人文與媒介"],
  "summary": null,
  "activities": [],
  "possibleOutputs": [],
  "offeringNote": "實際開課依當學年度課表",
  "sourceVersion": "115學年度"
}
```

### 8.2 欄位規則

- `id` 必須穩定，不以課名作唯一識別。
- `role` 可為 `foundation`、`application` 或 `integration`。
- `primaryTrack` 可為三個探索面向之一，也可為 `null`。
- 同一門課可有多個 `relatedTracks`，但介面不可因此暗示必須選擇固定路徑。
- 沒有可靠資料的 `summary`、`activities` 或 `possibleOutputs` 可以留空，前台不顯示空區塊。
- 課名、年級、學期、學分及必選修以正式課程清單為準。
- 資料需保留適用學年度。
- 若正式計畫書有模組分類，可保留 `module` 供行政對照，不必在前台顯示。

## 10. 驗收標準

由於時程不安排正式使用者測試，第一版以內容、功能及介面檢核為主。

### 10.1 內容

- 69門課程均可追溯至正式課程清單。
- 課名、年級、學期、學分及必選修資料正確。
- 網站清楚標示資料適用學年度。
- 所有頁面均顯示或可找到「實際開課依當學年度課表」。
- 沒有資料的課程不以生成或推測文字填補。
- 正式系名及30／26學分差異在上線前獲得確認或有適當說明。

### 10.2 理解

由系所內容負責人進行上線前走查，確認首頁在不操作的情況下即可看出：

- 四年學習的先後進程。
- 文學文化與人文方法是共同基礎。
- 三個探索面向不是固定分組。
- 專題、實習與畢業製作具有整合作用。
- 必修與選修之間的差異。

### 10.3 互動

- 年級及選修內容可正確展開與收合。
- 學期切換結果正確。
- 面向可單選、複選及清除。
- 篩選後共同基底與必修課仍可辨識。
- 課程詳情可開啟、關閉並回到原位置。
- 分享或重新整理網址可重建檢視狀態。
- 手機不需橫向縮放或拖曳即可完成主要操作。
- 鍵盤可操作所有核心功能。

### 10.4 品質

- 正式環境無阻斷操作的錯誤。
- 常見手機與桌機寬度沒有內容截斷、重疊或不可操作元件。
- 首屏內容及主要課程地圖具有合理載入速度。
- 基本SEO、分享預覽、HTTPS及錯誤頁設定完成。

## 13. 產品原則

1. **先讓人看懂，再提供更多功能。**
2. **年級是主軸，面向是探索工具。**
3. **共同基底不能被應用面向淹沒。**
4. **不把探索面向呈現成固定分流。**
5. **不把規劃課程誤寫成每年必然開設。**
6. **沒有可靠資料時，少寫比推測更可信。**
7. **互動必須幫助理解，不為互動而互動。**

## 14. 最終交付定義

第一版交付的是一個可公開、精緻且容易理解的四年課程地圖。使用者進入網站後，不需登入、不需測驗，也不需先做選擇，即可看見完整學習結構；並能透過年級、學期、探索面向及課程詳情逐步理解69門課程。

第一版的成功不以功能數量衡量，而以課程結構是否清楚、資料是否可信、手機操作是否流暢，以及整體呈現是否足以代表學系特色為準。
