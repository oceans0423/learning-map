## 1. 核心決策

網站首先回答：「本系有哪些課程？分成哪些領域？四年如何安排？我想了解的課在哪裡？」

個人星座只回答：「我感興趣的這些課，可以呈現成什麼樣子？」

因此只設計一條主要流程：**認識課程結構 → 找到課程 → 閱讀詳情**。加入我的課程與查看星座是途中可選的支線，不是入口門檻，也不是第二套選課系統。

星空是統一的視覺語言；正式分類、年級與必選修才是資訊結構。即使使用者完全不收藏，網站仍須完整、清楚、好用且有辨識度。

## 3. 資訊架構：一張地圖，兩個理解角度

```text
課程地圖（預設入口）
├─ 總覽：按領域／按年級（切換同一個總覽區，不是兩個產品）
├─ 課程結果：所選領域、年級或全部課程，共用列表與篩選
├─ 全站搜尋結果：涵蓋全部課程，可直接查看詳情
└─ 課程詳情：課程事實＋選用的「加入我的課程」

我的課程（次要入口）
├─ 感興趣的課程清單（預設）
└─ 用星座呈現（選用；同一份 course IDs）
```

主要導覽只需「課程地圖」與「我的課程」。搜尋是工具，不另起一個宇宙、測驗或航線頁。頁面以「課程地圖」為主標題；「星系」可以作輔助敘事，不能取代可理解的領域名稱。

全站只保留一份課程資料、一份感興趣課程集合、一個詳情入口。兩個總覽角度都通向同一套課程結果。

### 為什麼仍保留按年級看

只有領域分組是課程目錄，不足以完整交代課程地圖。學生也需要看大一到大四的分布、學期及必選修。因此年級視角與領域視角同屬主功能；個人星座不承擔這項責任。

按年級看只表達既有資料的安排，不自動推論先修鏈、能力解鎖或正式修課路線。

## 4. 首頁：先看見課程世界，再開始找課

### 首屏內容與順序

1. 緊湊標頭：學系名稱、課程地圖、我的課程入口。
2. 主標題「課程地圖」，一句用途說明；115 學年度／69 門等範圍資訊。
3. 「搜尋所有課程」輸入框。
4. 「按領域看／按年級看」切換控制。
5. 同一個總覽區：預設四大領域，切換後改成四個年級。
6. 「查看全部 69 門課程」入口與簡短資料來源說明。

不新增全螢幕形象區、長宇宙故事、四訊號說明卡、空收藏面板或星座任務進度。以一般 390×844 與 1440×1000 畫面為驗收尺寸：首屏應看到搜尋與至少一個完整領域入口；文字放大時以可達、可讀優先，不強制塞入一屏。

### 四個領域如何長得有特色

桌機以有序 2×2 的「星群入口」構成一幅總覽，不做需要拖曳、縮放才能操作的自由畫布。每個入口都有清楚文字區與少量星點／細線，整個入口可點按，不只小亮點可點。

四組星群可以有不同的簡潔幾何輪廓；這些是領域識別，不使用十二星座形狀，以免和個人星座混淆。輪廓不代表學術難度、課程先修或真實天文分類。星點作裝飾，不要求每個點對應一門課，課程數以文字為準。

每個入口只包含：領域名稱、課程數、一句已確認的導覽文案、查看課程提示。草案介紹未確認時，不用虛構課程成果補位。

### 四年視角

同一位置改為大一到大四的有序入口，顯示課程數，並提供上／下學期數量或分布摘要。階段文案沿用現有內容時仍須核對內容確認狀態，不把網站敘事當成正式培養成果保證。

切換總覽角度不改收藏；回到新角度的總覽，不偷偷帶入上一角度的領域／年級限制。上一個結果狀態可供返回使用，不暗中覆蓋。

## 5. 共用課程結果：一次專心看一個範圍

點領域後顯示該領域所有年級的課程；點年級後顯示該年級所有領域的課程。「查看全部」顯示全部 69 門。三種入口共用相同的資料查詢與結果元件，不各做一套選課頁。

### 控制與內容

- 頂部顯示來源與返回總覽，例如「課程地圖 › 敘事與內容創作」；標題、目前範圍、結果數清楚可見。
- 按領域進入：優先提供年級篩選；按年級進入：優先提供領域篩選；全部課程可使用兩者。
- 學期與必修／選修收在「更多篩選」。已啟用的條件與「清除篩選」必須可見，不能只藏在面板內。
- 所有啟用的條件用 AND 交集；沒有結果時顯示目前限制，提供清除額外篩選、返回總覽及查看全部。清除額外篩選保留入口範圍，不清除收藏。
- 結果依年級、學期、永久 ID 穩定排序；預設桌機每頁最多 12 門、手機每頁最多 6 門，提供上一頁／下一頁及位置計數，不無限向下堆課。
- 篩選改變後回第 1 頁；由詳情關閉或我的課程返回時恢復原條件、頁次及捲動位置。調整螢幕寬度以原可見課程為錨點換算頁次，不跳回首課。
- 網頁採正常文件流，不以固定視窗高度剪掉內容；結果清單可正常捲動，長課名自然換行，不靠省略號才容得下。

課程項目以完整課名為主，附年級／學期、必選修與學分。跨領域結果再顯示領域標籤。小星點與微弱光暈負責延續視覺，文字和足夠的點按範圍負責操作。

不在主要結果畫課程間的任意連線。領域裝飾線、年級排序與個人星座線各有不同用途，不能誤導成官方先修圖。

## 6. 搜尋與課程詳情：真正接得起來

### 全站搜尋

- 標明「搜尋所有課程」就必須涵蓋全部 69 門，不受所在領域、年級、星座或收藏狀態限制。
- 提交有效關鍵字後在主要內容區提供真正可點開的搜尋結果，明確標示「全部課程的搜尋結果」。不只顯示命中數、不讓舊篩選把命中課程再藏起來。
- 搜尋離開原瀏覽狀態時保留來源快照；清除搜尋後可回到來源，或明確選擇查看全部課程。
- 從我的課程／星座使用全站搜尋，導向同一結果區，個人資料不丟失。清單若另提供內部搜尋，必須標為「搜尋我的課程」，不能混用範圍。
- 保留目前字面搜尋的 Unicode 正規化與 IME 組字處理；不加自動選課、猜測人格、假智慧推薦。

### 詳情

第一層顯示課名、領域、年級、學期、必選修、學分與實際開課說明。尚未核定的內容不顯示成事實。正式面向與課程作用收在「課程定位」補充區；新探索訊號不在首版加入這裡增加負擔。

「加入我的課程／已加入」是次要操作，旁邊說明「記下感興趣的課程，並非正式選課」。不把收藏數說成修課完成數或學分達成率。

桌機沿用可讀的非 modal 側欄；手機沿用 modal 底部抽屜，具可見關閉鈕、Escape、焦點限制、背景隔離與捲動管理。不強制向下拖曳才可關閉。

關閉回到原課程來源；來源消失時回到該結果標題或穩定控制。瀏覽器 Back 先處理詳情，再按歷史回到前一範圍；深連結沒有站內來源時使用可預期的地圖出口，不任意退到站外。

## 7. 我的課程與個人星座：同一份內容，不增加第二套任務

### 我的課程預設是清單

主功能改版階段不擴充星座；整合後「我的課程」預設顯示感興趣的課名與基本資料，支援查看詳情、移除及最近一次復原。大量已加入課程同樣分頁，不能另造一份 69 門長牆。

零筆時只有簡短說明與「回課程地圖」，不顯示缺幾顆、待解鎖或未完成星座。首頁入口保持低強度，有選擇時才顯示數量；不彈出首次收藏教學或強迫註冊。

本機保存沿用既有主動同意機制，僅在此處說明實際保存狀態，不在一般瀏覽首頁展示存檔控制。未同意時不自動寫入，不把當次記憶體草稿說成永久保存；保存失敗也須誠實顯示。

### 用星座呈現

有選擇後提供次要操作「用星座呈現」。直接把同一份已選 course IDs 帶入固定造型；不再顯示原型裡另一個搜尋／勾選全課程的介面。要新增課程就回地圖，要移除就用同一個清單行為。

先重用單一天蠍座模板驗證整合。少量課程仍可觀看完整造型，空點只是裝飾，不代表需要補課；超過 11 門沿用既有分組星點與完整清單，不靜默截斷。星點可點開課程，但此模式不取代清楚的清單。

標示「這是你的探索圖像，連線不代表先修或正式修課安排」。預設靜態，不要求畫線、拖曳、移動或挑代表星。

### 後續才考慮

十二款固定模板、隨機第一次揭曉、換造型與命名可另外立項：隨機結果應穩定，換形狀不換課程、不重抽推薦，不當成人格測驗。星座課程推薦還需要另行審閱內容，不能由形狀或熱門性格印象自動推論學習適性。

不為本輪加入下載、分享、作品牆、徽章或新存檔格式。既有自由構圖、作品名稱、匯出功能與已保存資料暫時保留；整合前清查相容性，必要時對有舊作品的人提供明確的「既有作品」入口，而不是默默轉換或丟棄。新使用者不必看到舊編輯器選項。

## 9. 手機不是桌機星圖的縮小版

- 320–767 px：四領域改為縱向、緊湊的星群入口；完整長名稱與點按區共存。無水平拖曳宇宙、必需 pinch、長按或 hover。
- 768 px 以上：總覽可採 2×2；結果依實際可用寬度排版。只有容得下內容時才啟用側欄詳情，不能單看裝置名稱。
- 手機結果每頁預設 6 門；長文字／放大仍允許自然增高，分頁是控制資訊量而不是強制固定畫面高度。
- 篩選在明確的展開面板內；按鈕、狀態與結果數避免多層 sticky 疊加。一般標頭不常駐占用三分之一畫面。
- 手機詳情底部抽屜內部可捲，關閉與加入操作不被鍵盤／安全區遮住；旋轉與 resize 不丟狀態。
- 不新增四五項底部導航、懸浮星座邀請或大型固定收藏條。
- 主要操作以 44×44 CSS px 為設計目標，檢查相鄰命中區不重疊。200% 文字與實際瀏覽器放大另行驗證，不能只用改字級代替全部放大測試。

## 10. 動效：讓狀態變化有感，不讓內容等待

| 操作             | 初始動效提案                                   | 必須保留的行為                                 |
| ---------------- | ---------------------------------------------- | ---------------------------------------------- |
| 按鈕點按         | 80–120 ms 色彩／輪廓回饋                       | 命中區與文字不移位，Enter／Space 同等可用      |
| 進入領域或切年級 | 180–220 ms 局部淡入，位移不超過約 8 px         | 標題、範圍與資料立即更新，不全頁宇宙穿梭       |
| 手機詳情抽屜     | 200–240 ms 短距離交接                          | 可立即關閉，新操作不排隊等待動畫               |
| 加入我的課程     | 即時文字／勾選，必要時一次輕微局部亮起         | 計數與資料立即一致，不飛行到離屏／inert 目的地 |
| 個人星座         | 預設靜態；若另行確認，可在主動切入時一次短畫線 | 不自動播放長揭曉，不阻擋點課程，離開即停止     |

手機不以 hover 作為必要訊息來源；預設不加常駐漂浮、粒子、視差、呼吸按鈕或陀螺儀。動畫只用局部 opacity／transform 等低成本變化，避免整幅圖片 blur 或重排。

reduced-motion 下直接交接內容、保留靜態狀態提示。動效不持有收藏或路由狀態，途中反向、快速切頁、Back 與縮放以最新操作為準。上述時間是待測起點，不是已驗證流暢性的保證。

本輪不決定新的 URL 參數名稱。實作時先清查既有 sem／focus／open／course／atlas／signals 與 `#scorpius` 連結：保留舊語意，不把正式面向參數解釋成領域或星座。新範圍使用獨立、可驗證參數；無效條件回安全預設。

舊連結中的探索訊號即使不再作主要控制，也不能隱形影響新版結果；需明確相容提示或解除該限制，保留舊頁／文件的可追溯性。舊原型深連結保留為評估入口，正式首頁不與主地圖並列宣傳。

每次結構調整都需核對保存同意、舊作品、最近復原、課程深連結與焦點還原。不部署、不提交、不清空真實瀏覽器資料，除非另有明確要求。

## 12. 分階段小任務

使用新的 MAP 編號，不重寫已完成的 UI-01～UI-19 進度。以下描述每項交付與驗收，實際狀態見 [MAP 開發進度](MAP_TASK_PROGRESS.md)，不以文件存在代替完成驗證。

### MAP-01｜資料展示與篩選契約

交付：四領域前台名稱映射、共用查詢／計數規則與測試；無介面大改。

驗收：全部 69 個唯一 ID 可達；13／26／12／18 與 12／23／23／11 正確；必選修 15／54；null 面向課程仍納入；原資料 hash 不變。導覽文案未確認時不輸出虛構課程摘要。

### MAP-02｜共用視覺與緊湊頁框

交付：深藍語意 token、可及按鈕狀態、標頭／搜尋／內容容器與背景降級。

驗收：320／390／768／1024／1440 px 不水平溢出；文字／控制對比量測；圖片失敗仍可找課；首屏搜尋和至少一個完整主入口可見；不新增主題切換或重型效果依賴。

交付：同一總覽區的兩個視角、四領域星群、四年分布、查看全部入口。

### MAP-04｜共用結果與分頁

交付：領域／年級／全部三種來源、交集篩選、計數、分頁、清除與空結果。

驗收：逐頁遍歷所有 69 ID 且不漏不重複；切篩選回首頁；resize 保留錨點；長課名與200%文字可讀；手機不因追加結果形成無限課程牆。

### MAP-05｜搜尋、詳情與返回旅程

交付：真正可開啟的跨視圖搜尋結果、共用詳情、新舊URL相容、來源／頁次／焦點還原。

驗收：從任何視圖搜同一課都可直達；IME 組字不誤提交；Back／Escape／深連結／來源消失有合理出口；不收藏也能完成四領域、四年、搜尋與詳情全旅程。核定投影仍遵守資料狀態。

### MAP-06｜選用的我的課程與星座整合

交付：我的課程預設清單、移除／復原、本機保存狀態、同清單切入固定天蠍座；移除星座專用全課程選擇流程。

驗收：0／1／2／8／12／69 門均可處理；清單與星座同 IDs；超量星點分組且清單完整；不要求集滿；舊作品與保存同意不被改寫。換形狀、隨機、命名擴充與推薦不在此任務偷加。

### MAP-07｜實際畫面、素材與品質關卡

交付：適尺寸背景、瀏覽器旅程、截圖、效能與限制紀錄。

驗收：主要桌機／手機尺寸、低高度、文字放大、實際瀏覽器 zoom、全鍵盤、reduced-motion、圖片載入失敗、保存失敗與長清單。自動可及掃描加焦點走查；可取得真實手機／讀屏時另測，未測項明列，不宣稱全面符合。

素材壓縮以桌機約 300 KB、手機約 150 KB 的首屏背景為起始預算，依漸層品質與實測調整；這是目標，不是目前原PNG已達到。記錄同環境的前後載入與操作表現，不以桌機「看起來順」代替實機證據。

### 開發順序與停止點

**先 MAP-01 → MAP-02 → MAP-03 → MAP-04 → MAP-05 → MAP-07（主線驗收）**。

先讓使用者確認主要地圖是否清楚、手機找課是否自然；通過後再做 **MAP-06 → MAP-07（個人功能回歸）**。十二星座與推薦另立任務，不因前版已做收藏就再次把它推到主角位置。

## 13. 最終驗收：不是功能數量，是學生能否理解

主線設計需讓第一次進站的學生，在不收藏、不看長教學的情況下：

1. 說出網站提供四個課程領域，並理解這是同一個學系的課程結構。
2. 找到自己年級的必修，讀到學期與學分，再回到原位置。
3. 找到跨年級的感興趣課程，不被隱形篩選阻擋。
4. 理解地圖的線條不等於先修關係，規劃課程不等於本期保證開課。
5. 知道「我的課程」只是個人記錄，可以完全不用。

學生直覺性仍需真人測試。建議用以上任務觀察是否能無提示完成，記錄迷路點與操作步數；測試人數、時間門檻與招募另行決定，不把專家推測寫成已驗證結果。
