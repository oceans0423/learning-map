## 1. 提案主張與範圍

**用四個明亮的插畫場景吸引探索，用四年安排解釋課程，用目標與能力讓安排有意義。**

產品仍是一個功能性的課程地圖。學生不收藏、不看角色、不閱讀長篇故事，也應該能了解四大領域、找到全部課程、看懂年級安排與課程作用。

「四域探索圖鑑」可作為內部工作名稱；前台主標題保留「課程地圖」，避免使用者不知道這個網站是做什麼的。

### 訪談已確認的條件

- 使用者主要以自己的手機或電腦瀏覽，手機是優先設計情境。
- 四大領域一開始全部看見；拖曳／滑動只切換焦點與簡介，再點明確入口深入。
- 圖像採插畫場景，以環境與物件為主，整體明亮、有活力、有憧憬。
- 進入領域後以上下滑動為主要探索方式，畫面安定、內容自然進場、少量物件動態。
- 先理解領域的內容與目標，再看課程如何組成，以及想培養的能力。
- 四年安排與學習意義並存；每門課以一至兩個主要能力指標協助解讀。
- 收藏是自願支線。先探索，再主動揭曉探索角色，也能看其他角色。
- 角色具有想像力與樂趣；現實的能力及專業方向作為附註，不再要求星座形式。

以下色票、場景名稱、版面細節與動效時間用於下一步樣張；角色示例用於說明收藏支線的體驗。

### 控制規模

本案包含：四領域入口、四年課程地圖、搜尋與全部課程、課程詳情、選用收藏與角色結果。

不新增：學系形象長頁、案例庫、作品展館、招生表單、多人世界、自由走動、3D 遊戲、闖關任務、排行榜或登入系統。既有命名／下載等功能另做相容性盤點，不在本提案擴充。

## 3. 資訊架構：主體一張地圖，支線一份收藏

```text
課程地圖
├─ 四領域入口：四個場景同時可見 → 聚焦比較 → 點擊探索
├─ 課程地圖內容：領域／全系範圍 + 四年安排
│  ├─ 簡短學習目標與主要能力
│  ├─ 年級／學期／課程作用
│  └─ 共用課程詳情
└─ 搜尋所有課程：直接到結果與詳情

我的課程（選用，同一份 course IDs）
├─ 收藏清單、移除與既有保存控制
├─ 主動揭曉探索角色
└─ 看看其他角色 → 相關課程 → 回到同一張地圖
```

主導覽只需「課程地圖」與「我的課程」。角色圖鑑是我的課程的延伸，不另設一個與課程地圖競爭的主站。

入口始終提供「查看全部課程」與「搜尋所有課程」。深連結、已有明確查找意圖的人可以直接到課程；不強制先選世界、播放動畫或收藏。

四年是閱讀骨架，學習目標與能力是解讀層，不設「年級模式／能力模式」兩套主要閱讀系統。所選領域與「全系」是同一張地圖的範圍變更，不複製課程資料或收藏。

## 4. 視覺方向：晴日裡的四個探索場景

### 構圖與畫風

設計意圖：**像站在一幅明亮的創作場景前，先認出四種學習，再選一個地方靠近閱讀。** 品類是課程內容探索工具；首屏主角是四個領域，不是招生口號或角色測驗。

畫風採城市觀察速寫式的手繪場景：自然不規則的細墨線、疏密變化、少量排線與局部淡水彩，保留暖白紙面的呼吸感。採自然觀看高度與輕微斜向透視，共同的明亮日光；手繪不等於復古或懷舊。場景有前、中、後景與延伸，但不做自由走動或鏡頭視差。

每個領域是一個連續場景，以一種正在進行的活動組織物件、空間與使用痕跡，不固定限制物件數量。故事線索有主次，關鍵材料與結果之間有可觀看的關係。大幅聚焦圖保留完整空間，全覽縮圖另取辨識局部，不要求整張母圖縮到 120 px。四個領域以活動與空間構圖區分，不只換顏色；避免白底圖標集合、孤立工作桌、軸測微縮模型或光滑的 3D 展示品。

已選定構圖是 B「四領域全覽＋大幅聚焦場景」：四個可見入口提供全貌，較大的場景呈現目前聚焦領域，見第 6 節。A「四域共景」保留為比較候選：四組場景共用背景與光向，按 2×2 空間位置組成一幅完整圖，不加四個圓角卡片外殼；不是後續實作主版型。

同一場景有三個用途：局部裁切提供入口識別、完整構圖承接聚焦比較、內頁延續同一場景。這是「走進去」的連續感，並不要求變成沉浸遊戲。圖內不加標題、註解或故事文字，領域名稱與課程目錄由網頁呈現；圖片不代替課程事實。

- 圖像與課名不爭搶：文字放在穩定的閱讀表面，不直接壓在複雜插畫上。
- 領域切換時，選中輪廓、代表物件與簡介同步，控制位置固定；全覽中的四個位置不搬動。
- 不用星點、粒子或金色連線作為全站預設語言。
- 活力集中在插畫與當前行動；閱讀區仍用深色文字、清楚留白，不讓四種領域色同時搶課名。
- 角色圖片可以有完整人物造型；這與四大領域「環境／物件為主」是不同層級。

v2 純色對比重新量測：主要文字／暖白 12.61:1，次要文字／暖白 6.63:1，主要文字／白色 13.30:1，次要文字／白色 6.99:1，白字／行動色 5.84:1，行動色／暖白 5.54:1。

這些是指定純色組合，不是整頁可及性通過證據。四種領域色不是通用文字背景：例如主要文字／紫色 3.26:1、主要文字／天藍 4.49:1，白字／四種領域色也都未達一般文字 4.5:1。分類名稱仍用深字放在白／暖白表面，顏色僅作小標記；圖片上的字、必要邊界、focus 與 disabled 狀態另行量測。

色票是樣張起點，不以換色代替美術判斷。先把數位場景放進已選定 B 的手機頁：無文字也能感覺到地方材料如何被整理與呈現、能看清課名、整體具有明亮創作感，再據圖像調整分類色。插畫以暖深灰褐墨線和少量柔和洗色為主，不強制大面積精確色碼；介面文字與操作色仍保留可讀的純色。圖像未到位時不把「對比合格」當成「審美通過」。

### 字體與尺度

繁體中文以現有清楚的系統字／回退字型為主，暫不為提案新增外部字型依賴。手機頁名約 24–28 CSS px／600–700 字重，內文與課名 16–18 px／行高約 1.6，資訊標記以 14 px 為起點。不要用巨大口號擠掉四個領域，也不把長課名壓成小字。

使用 4／8／12／16／24／32 px 共用間距；手機約 16 px 左右留白。互動命中區以至少 44×44 CSS px 為設計目標，與鄰近按鈕分離。200% 文字與窄螢幕時允許自然增高，不為塞滿首屏而裁切。

控制共用約 10 px 圓角、清楚文字與短促按壓；focus 以獨立輪廓表示，選中另有勾選／名稱，不混為同一狀態。課程目錄先用對齊與留白，不再逐行套卡片。通用操作沿用現有圖示；只為四個代表物件製作專屬視覺，不新增一整套圖示庫。

### 素材的最小製作方式

先完成數位人文一張母圖：**透過地方故事共作室的場景，表現觀察材料如何被整理、連結與數位呈現。** 母圖放入 B 的全覽縮圖、大場景與同一領域內頁，確認構圖、尺度、閱讀與風格，再擴展其他三張。

美術簡報：自然觀看視角、細墨線、局部淡水彩、暖白紙底與明亮日光；橫向 4:3 的連續場景，以前、中、後景組織視線。關鍵故事線索留在安全裁切區，留白提供呼吸，不將空間壓成置中物件。不得畫入任何標題、註解、課名、按鈕、真實程式碼或假 UI 文字。全覽小圖裁出辨識局部，大圖保留空間；不把完整場景等比縮到看不清。詳見最新素材提示詞。

- 同一母圖用於共景中的一區、B 版聚焦圖與領域頁，不為兩個版型各生成一套素材。
- 首版母圖加少量可分離物件即可；若要動態，另提供相應透明圖層，不要求程式猜測平面圖中物件的位置與遮擋。
- 手機與桌機共用畫風，依重點構圖輸出不同裁切；領域標題、數量與按鈕都由網頁渲染，不寫進圖片。
- 先做一個探索角色的風格樣張。其餘角色數量由課程組合與素材負擔決定，不預先要求十二個。
- 圖片失敗或尚未完成時，以靜態形狀與完整文字降級，所有課程仍可達。
- 原始圖保留；後續另製 WebP／AVIF 與適尺寸版本，不覆寫原 PNG。

已有的深藍底景、四張抽象雕塑與四張星座圖卡均保留。星座圖卡存於 `public/images/area-cards/`，此次可作歷史參考，不要求沿用為新版插畫，也不在提案階段刪除。

聚焦帶可短距離跟手、放開後到位；直向及未明確偏向橫向的手勢保持原生捲動。第一／最後顯示邊界與按鈕不可前進狀態，不偷偷循環。沒有平移地圖、縮放、熱區尋寶或自己拖動場景的要求。

## 8. 代表性互動與動效契約

### 三個基本動作，用同一套因果關係串起來

共同手感是「編輯桌上的輕按與滑入到位」：小控制短促，大區域不晃動；被選的物件、領域名稱與目的地保持連續。以下是原型契約，不是已實作或已量測的流暢性保證。操作結果即時更新，不等待演出結束。

1. **主操作回饋：輕按到位。**「探索［領域］」按下時約 80 ms 內給回饋，縮至約 0.98 或下移 1 px，放開還原，命中區與周邊布局不搬動。收藏沿用同一手感，勾選與計數即時交付結果，不另做炫光、波紋及慶祝三套效果。
2. **狀態交接：同一物件，換一個閱讀位置。**往下一領域，預覽內容向左讓位、下一項由右側進入；上一領域反向。共景固定不滑走。按探索後，同一代表物件在內頁標題旁延續，配合約 180–240 ms 的局部淡入／滑入，而不是整頁飛行或巨大鏡頭放大。首版以物件重用與穩定轉場完成，不以脆弱的跨頁形變作為必要條件；缺圖、快速返回或縮放時直接到位。
3. **首次出場：畫面先可用，少量物件才落定。**四個完整領域名稱與所有操作立即出現；代表物件可由約 4–8 px 的局部位移落定，輔物件晚約 40–60 ms 跟上，總長約 400–600 ms 以內。不是逐個解鎖領域，也不設開場影片、載入倒數或不可略過遮罩。每次進站首次入口呈現一次，返回、改視口與重新渲染不重播；圖片晚到時維持原本預留空間，不能推開已在閱讀的內容。

reduced-motion 下三個動作全部直接到位，保留勾選、名稱、序號與目的地辨識。第一次出場只作用於插畫，不把課程文字藏到捲動觸發後才出現。

| 跳到年級       | 四年摘要的年級連結到對應標題，課程一直可讀，不逐列演出                  | 返回與詳情關閉恢復位置；原生錨點可用；減少動效不做平滑捲動                          |
| 查看／關閉詳情 | 桌機側欄或手機抽屜從相應邊緣滑入，進入約 220–280 ms，退出較短           | 可見關閉鈕、Escape／Back 與焦點恢復；可立刻取消；減少動效直接顯示                   |
| 加入／移除收藏 | 勾選／文字與計數即時更新，約 80–120 ms 局部按壓回饋                     | 同按鈕可移除，沿用既有復原；清篩選不清收藏；不要求拖曳，也不播放每次慶祝            |
| 主動揭曉角色   | 約 300–450 ms 插畫、稱號與依據交接，結果可立即閱讀                      | 可略過、回收藏或繼續探索；減少動效直接顯示；不播放不可略過影片                      |

本頁是課程探索工具，不是品牌落地長頁，不增加滑動驅動的場景敘事或新動效庫。若素材有可分離圖層，數位場景可在首次聚焦時讓資料積木對齊文本板，一次短促變化就是記憶點；沒有圖層時用靜態母圖，不對整張圖片硬加浮動。閱讀中不使用持續全場旋轉、鏡頭推進、捲動鎖定、跟隨游標或陀螺儀。

動效以局部 opacity／transform 為主；離開畫面或頁面隱藏時停止，尊重 reduced-motion。靜態畫面必須能完成所有理解與操作。

互動樣張已為首次出場、領域切換與收藏回饋留下錄屏及開始／中間／結束三幀，詳見 [交接與證據](design/four-worlds-20261010/README.md)。後續仍須在真實手機測快速連按、斜向觸控及作業系統減少動效設定；不報未測量的幀率、動效分數或「已流暢」。

## 9. 探索角色：記住選擇，也看懂選擇

主流程：**探索 → 自願收藏 → 在我的課程主動揭曉 → 看依據 → 看其他角色或繼續探索。**

入口可以有一句低強度預告「你的探索，會形成什麼角色？」；不展示大型空角色、缺幾門、待解鎖或完成百分比。沒有收藏仍可從我的課程的次要入口看角色圖鑑；不因支線存在而讓空收藏阻擋主站。

### 一張角色結果的三層內容

1. **想像層**：角色插畫、稱號與一小段故事。
2. **依據層**：哪些實際收藏形成這個探索方向、涉及哪些想發展的能力。
3. **現實附註**：可探索的專業方向，不寫職業資格、適性判定或能力達成保證。

示例「記憶修補師」：想像上找回散落的故事；現實附註可探索文化研究、數位典藏或策展。這只是角色架構示意，不是已完成的能力／課程對照，也不限制所有角色都走人文懷舊題材。

### 配對與圖鑑的設計邊界

- 角色根據課程組合與能力重點，解釋使用者的探索方向。角色類別與配對規則在主地圖完成後整理，不直接沿用星座性格權重。
- 可用簡單、版本化、可說明的相似度；相同收藏與規則版本得到穩定結果，不需要執行期 AI 或每次載入隨機換角色。
- 跨域選擇也是有效組合，不強迫每個人只屬於一個領域。角色不等於四大領域重新分類。
- 不要求集滿、四年均勾選或指定課程才能查看。有少量收藏可提供暫定探索方向；不足以區分時誠實標示「目前可探索的方向」，不要製造精確分數或稀有度。
- 結果依據只引用實際收藏。圖鑑的示例組合不自動加入；點其他角色也不換掉原收藏。
- 同門課可關聯不同角色，角色內以 ID 去重。關聯課程按真實四年分布呈現，不為湊人數／年級改正式資料。
- 收藏改變後提示結果可更新，由使用者主動查看；不在每次增刪課程後跳出角色。
- 自選欣賞其他角色時，標明「正在查看其他角色」，不冒充是由自己的收藏配對而來。
- 舊星座資料、命名、匯出與作品先盤點相容性；不自動轉換成新角色、覆蓋或刪除。新舊結果不建立第二份課程收藏。

### 介紹式文案的寫法

1. **領域先說目標：**說明主要學習內容與想培養的能力，幫助學生知道為什麼值得探索。
2. **課程說具體動作：**用「整理文本、分析資料、組織內容、設計提案」等表達，避免只把課名換句話說。
3. **能力說如何運用：**例如「文本分析」可補一句「從文本中整理線索，理解內容與脈絡」，比只列抽象標籤更容易記住。
4. **四年說學習關係：**從基礎理解到工具應用、整合與實踐，說明課程放在一起的意義。
5. **語氣明確而親近：**直接介紹學習方向，頁面重點留給學生的理解與操作。

### 能力整理與 UI 同步進行

前台每門課突出一至兩個主要能力，保持閱讀焦點。更完整的對應留在內容資料中，課程列表不塞入整份能力研究。

整理方式：

1. 以四大領域、69 門課程與學系的學習方向，整理每門課的介紹。
2. 從能力訪談資料提取貼近本系的行為與應用情境，改寫成學生容易理解的用語。
3. 先整理代表課程的一至兩個能力重點，與版面一起試讀，再逐步延伸到全部課程。
4. 依課程關係收斂能力類別，保留跨域組合的彈性。
5. 主地圖完成後，以同一份課程與能力對應發展角色組合及結果介紹。

課程介紹、能力與角色對應使用獨立內容資料，保留 course ID、能力名稱、來源記錄與修訂版本，便於日後更新；課名、年級、學期、必選修與學分沿用既有課程資料。

## 11. 風險與驗證計畫

本提案來自利害關係人訪談與現有資料核對，不是高中生實測結論。網站原有工程測試的通過，也不代表新方案已好用或美觀。

### 原型先驗證三件事

1. **入口理解**：在 A／B 真實尺寸樣張中，學生都看得出四個領域，能點選比較、找到探索按鈕；滑動區及方向清楚，不在共景上嘗試平移或猜熱區。
2. **課程理解**：不收藏也能找到指定課程，看懂年級／學期／必選修，並用自己的話說出領域與幾門課的學習關聯。
3. **支線理解**：願意收藏的人知道何時揭曉、角色從何而來；不收藏的人不覺得缺少必要步驟。

建議先以約 5–8 位高中生做形成性試用，包含不同熟悉程度的使用者；這是找問題的小樣本，不用來宣稱統計代表性。另做鍵盤、讀屏與減少動效走查，若無法取得對應使用者或裝置，明列未驗證項。

測試任務包括：找全系大二必修、到另一領域找課並返回、用第 10 節五門課的介紹解釋領域目標與兩門課的關係、辨識收藏與正式選課的差別、主動查看其他角色而不改掉收藏。先記錄完成、誤解與迷路點，不以停留越久當成成功。另外測試完整領域與 26 門最大領域的長頁閱讀。

### 工程與素材驗收起點

- 遍歷 69 個唯一 ID，與四領域／四年／必選修計數一致；介紹與能力資料的補充不影響課程完整性。
- 320／390／768／1024／1440 CSS px、低高度、橫向、200% 文字與瀏覽器 zoom 皆可讀、可達。
- 用「古典文獻的數據化與文化IP轉譯」等真實長課名驗證換行、詳情與收藏布局。
- 分別驗證 A 的四區輪廓與 B 的全覽導覽；全覽標籤不能靠 hover 才讀到。26 門領域與 69 門全系總覽連續可讀；只有查找清單可以分頁。
- 全鍵盤、焦點還原、Back／Escape、觸控斜向手勢、快速反向及 reduced-motion 可完成相同主任務。
- 圖片失敗、慢速載入與儲存失敗可繼續找課，不能聲稱已永久保存但實際未成功。
- 配色在真實圖像、所有控制狀態中量測；本文純色數字不是整頁 WCAG 認證。
- 首屏四個領域縮圖的傳輸量合計先以約 300 KB 為待測預算；不先載入所有高清角色與場景原圖。必要素材分尺寸、延後非首屏載入，不新增重型 3D 依賴。
- 在實際手機測手勢與捲動，建立同環境載入／操作基準；沒有實機證據前不宣稱已流暢。

## 13. 本提案的取捨與下一步

採用四年骨架，保留了課程地圖的功能性；目標與能力協助理解安排，避免只有課名；插畫場景與角色成果提供探索與記憶點。這三者有主次，不各自發展成一套大型產品。

保留已確認的明亮插畫、手機優先、四域全覽與課程地圖定位，不再重開風格訪談。接下來透過小樣處理兩件事：

1. **已選 B 的圖像整合：**四張母圖已放進全覽縮圖與大場景；確認完整系列的輪廓、文字與探索按鈕，必要時微調裁切。不重開版型選擇。
2. **介紹可讀性：**把五門課程介紹與四年解釋放進畫面，檢查學生是否能說出課程在做什麼、為何這樣安排，依閱讀結果調整文字。

共同原則已寫入修訂：四年地圖不收合切碎，查找清單才分頁；圖與版面共同試作，課程主線先完成，角色支線延後。色票依同一母圖與真實文字樣張調整，不再另提一組暗色保底風格。

場景名稱、能力類別與逐課介紹隨樣張共同完善；角色數量與配對規則在主地圖完成後展開。既有深色網站在新版製作期間繼續可用。
