日期：2026-10-10。性質：設計討論小樣，尚未接入正式網站。

最新進度：已由數位人文 12 門延展至全部四領域、69 門課程。每門有一句介紹、一至兩個能力重點與一組主要學習關聯；共 13 組，每組 4–8 門。只改本目錄的小樣與內容，不改原 B 入口或正式網站。

## 如何查看

用瀏覽器開啟 [四幕並排分鏡](storyboard.html)，再按「開啟操作版」。不要用編輯器的文字預覽判斷畫面。

本機預覽服務啟動時，可直接開啟 [四幕比較頁](http://127.0.0.1:8776/doc/design/four-worlds-20261010/learning-relations/storyboard.html) 或 [互動操作版](http://127.0.0.1:8776/doc/design/four-worlds-20261010/learning-relations/storyboard.html?mode=screen)。若本機服務已停止，在專案根目錄執行 `python -m http.server 8776 --bind 127.0.0.1` 後再開啟。

操作版是同一個 HTML 的 `?mode=screen`；四幕可用 `&state=overview`、`detail`、`relations`、`return` 直接開啟。檔案不需打包、不需外部 CDN，可直接以 file URL 使用；所有資料、CSS、JS 與 Alpine 都來自本機。

`&area=thinking`／`narrative`／`digital`／`culture` 選擇領域；預設數位人文，未知領域亦回到數位人文。四個入口始終可見，保留完整名稱及 13／26／12／18 門數量。`&state=relations&course=course-046&area=narrative` 可直接查看自然書寫的跨域關聯；未提供課程或課程不屬於此領域時使用代表課。

## 本輪主張

四年是穩定的閱讀骨架，學習關聯是需要時才展開的解讀層。不是第二套能力模式，不改四年排序，不把全部課程藏成一條必修鏈。

沿用使用者已選定的 B 版方向、暖白閱讀底、深色文字、藍色操作與既有四張手繪縮圖。本輪只深化領域內頁；原 B 版、正式網站、課程來源與收藏都沒有修改。樣張的「四大領域」回到原 B 入口，原 B 尚未接入這套新關聯。

## 四幕

1. 四年總覽：每個領域的全部課程連續可讀，不收合、不分頁；課名、學期與必選修可見，課名下直接說明學習內容。
2. 課程詳情：各領域有代表課，所有 69 門均可點開；先看課程內容、事實與一至兩個能力。
3. 學習關聯：按「看這些課如何連起來」，在同一個面板中展開一組 4–8 門課程與連結理由；依實際開課年級排列，不強湊四年或視為先修鏈。
4. 返回：關閉後恢復原課程的操作焦點與開啟前的捲動位置，其他課程不消失。

相關課程可在同一面板內切換，有可見的回到前一門課入口；Escape 關閉面板，瀏覽器 Back 逐步回到前一狀態。面板使用原生 dialog 隔離背景。關聯沒有獨立頁面、第二層抽屜或必須觀看的動畫。

換到跨領域課程時，詳情與關聯列顯示其所屬領域，保留當前關聯組，不把主地圖切到別處。從相關課程再展開關聯後，按「回到前一門課」會直接回到那門課的原狀態與面板捲動位置；不只退一次展開操作。

## 內容與資料

- `learning-data.js` 由 `build-data.mjs` 產生 69 門課的 ID、課名、年級、學期、必選修、學分與原分類；驗證逐筆對照 `src/data/courses.json`。來源不變，原分類「文學創作」只在前台顯示為「敘事與內容創作」。
- 五門數位代表課的介紹與能力沿用提案第 10 節，另外七門保留第一輪內容。新補 57 門與 12 組關聯，全部共 13 組。介紹、能力與關聯是依課名及學系方向撰寫的設計內容，尚未逐筆對照能力研究 metadata；不是既有課綱、合作成果或學生成果。
- 內容來源集中在 [editorial.mjs](editorial.mjs)，課程事實與內容分開維護；完整逐課介紹及每組連結理由可讀 [CONTENT.md](CONTENT.md)。每門從總覽點開只呈現一組主要關聯，不額外增加能力模式或關聯圖鑑。
- 關聯是「共同的學習方向」，不是正式先修、修課建議唯一順序、能力等級或完成進度。
- 不新增收藏、登入、角色、搜尋或正式選課功能；回到四大領域的入口直接連至原 B 版。

## 動效與減法

使用 `UX Architect` 確認閱讀層級、同面板操作與焦點返回，使用 `oil-ui` 的 visual-language、motion、tools 製作可操作小樣。依 skill 保留已確認方向，不重開風格選擇。

三處基本動效：按壓約 100ms 內給局部回饋；詳情由底部 12px／240ms 滑入，關聯以 6px／200ms 局部顯現；首次進入只讓縮圖以 4px／360ms 落定。內容即時可讀，不等待動畫結束。reduced-motion 直接到位。短距離位移沒有宣稱為跨頁共享元素形變。

刪減：沒有領域內頁的大幅重複封面、逐列「查看詳情」按鈕、滿屏跨年級線條、重複卡片外框、收藏提示或角色預告。保留完整課名、課程事實、學習介紹、關聯理由及返回操作。
