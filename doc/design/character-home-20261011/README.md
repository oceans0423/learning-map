## 開啟

在專案根目錄執行：

```powershell
node doc/design/character-home-20261011/serve.mjs
```

瀏覽 `http://127.0.0.1:4175/`。不要直接雙擊 HTML；課程預覽需要本機 HTTP 讀取 JSON。若伺服器已開啟，不需重複執行。

## 採用的共同詞彙與具體規格

依據 `doc/ui-design/UI_Core_Application_Examples_v1.csv` 及 Recipes；示範數值依本次人物資產調整。UI Designer 技能用於建立色彩、字級、間距及元件狀態基礎，不套用其他 UI 風格模板。

|術語／對應需求|作用區塊|本次規格|
|---|---|---|
|Visual Hierarchy 視覺層級（UI-02-023）：先 Logo，再大標題，再人物|首頁整體|內容最大 1200px；Logo 最大 390px；標題桌面最大 80px、手機 51px；四領域圖片高 320px、手機 310px；專業角色圖片高 225 / 220px|
|Whitespace 留白（UI-03-012）：人物不要被厚重卡片包起來|人物舞台、區塊間距|暖紙色 #f6f2e9、墨色 #292e29、綠色 #3c5745；四領域透明按鈕底、淡色背景圓面；專業區與主舞台分隔 72px，手機 40px|
|Responsive Web Design（UI-14-001）：手機同樣能探索|人物與介紹|大於 700px 四領域並列；手機單人置中、鄰項局部露出，另有四名稱快捷選取；八專業角色橫向瀏覽，桌面約 4–5 位、手機約 2 位|
|Microinteraction（UI-13-001）、Easing（UI-13-021）、Duration（UI-13-019）|人物選取、懸停|選取縮放 1.04、200ms，淡色底面 220ms，cubic-bezier(.2,0,0,1)；文字「目前選取」及底線同步，不只靠顏色|
|Interruptible Animation（UI-13-050）|滑動、快速選角|使用原生捲動，沒有鎖住操作或播放序列；捲動停止約 140ms 後以最近人物同步介紹；點選只改介紹，不自動跳頁|
|Keyboard Navigation（UI-15-002）、Focus Indicator（UI-15-003）、Touch Target（UI-15-007）|所有入口|原生按鈕／連結；Tab、Enter、Space；領域另支援方向鍵與 Home / End；3px 焦點框；箭頭與快捷按鈕至少 44px 高|
|Reduced Motion（UI-15-018）|整頁|偏好減少動態時取消縮放、懸停位移與平滑捲動，保留直接選取回饋|
|Modal Dialog（UI-08-043）、Focus Restoration（UI-15-006）|角色介紹、唯讀課程預覽|原生 dialog、Escape／關閉鈕、開啟聚焦關閉鈕，關閉返回來源；背景不可操作|

補充實作術語：水平角色瀏覽／Carousel 與 CSS Scroll Snap（捲動吸附）是本次使用的技術描述，不宣稱其條目存在於目前 80 筆範例表。

## 已完成與範圍界線

- 四大領域：觀察家、人文思維與方法；說書人、敘事與內容創作；解碼師、數位人文；設計師、文化創意與社會設計。
- 八個專業角色含最新改名「探索者」，不以每領域兩人固定配對。
- 四領域入口及「全部課程」提供唯讀真實課程列表，讀取 `doc/course/courses_v1.json`；課名、年級、學分、必選修直接取原資料。課程載入有失敗提示及重試。
- 角色介紹是探索文案，不是能力測驗或職涯保證。
- 未製作收藏、課程詳情、能力計算、個人角色生成及正式網站整合。
- 原始 PNG 保留；13 張衍生 WebP 只裁透明外圍、等比縮小、壓縮，沒有重繪人物。總計約 0.93MB（十進位），報告見 `assets/report.json`。

## 假設與取捨

- 先採暖色淺底、裝置系統中文字體；不額外載入網路字型，跨裝置字形會不同。
- 人物共享顯示高度，未改各自比例；寬帽／披風較寬的角色會受容器限制，需由使用者視覺確認。
- 手機四位人物不能同時放大展示，因此用快捷名稱、箭頭和局部鄰項補足發現性；沒有自動輪播，也不接管垂直捲動。
- 專業角色仍保留選用地位；不先選人也能看全部課程。此頁不是先前被否定的強迫分類流程。
- 目前只用圖片與輕微 CSS 動效，不建立旋轉 3D 模型。
