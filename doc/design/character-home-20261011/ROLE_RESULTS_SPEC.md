# 我的探索｜角色方向結果區

## 範圍與假設

只修改獨立樣張 `courses.html?view=saved`，保留首頁、69 課程、原收藏儲存方式與能力方向。學生已能收藏，但不一定想看角色；沒有角色結果持久化、帳號同步或自動判定。使用已確認造型的透明 WebP，不改圖或生成新素材。

採 UI Designer 的層級與狀態設計、Frontend Developer 的元件隔離與漸進載入；不使用 oil-ui／oil-ui-pro。這些技能使角色結果成為獨立、可選的元件，資料失敗不拖累課程與收藏。

## 布局與外觀

- 結果入口位於介紹下方、既有領域／能力摘要之前；可直接跳到收藏課程，角色不是閱讀阻擋。
- 容器沿用頁面寬度，淺橄欖背景 `#eeeee2`、邊線 `#b7c1ab`、8px 圓角、桌面 28px／手機 20×16px 內距。
- 卡片奶油白 `#fffdf8`、6px 圓角、桌面 22px／手機 18×14px 內距；人物桌面 110×210px、手機 84×180px，object-fit:contain，不裁切。
- 主色沿用深綠 `#3c5745`、墨色 `#292e29`、次文字 `#62665c`；注意文字 `#874225`。不加光暈、玻璃模糊、徽章階級或適配百分比。
- 桌面保持兩欄，即使單一方向也不放大到像唯一指定；手機一欄避免橫向選擇隱藏候選。

## 狀態與互動

1. 初始不載入角色資料、不執行判讀、不顯示預設角色。零收藏也可按查看。
2. 主動按下後取得 `role-data.json`，用相同純判讀函式處理當下收藏；資料經結構檢查後才判讀。
3. 呈現單一／雙向／多元／線索不足，焦點移至結果標題（不強制捲動）；狀態區以簡短文字播報。
4. 每張卡顯示角色、工作面向、單課暫定提示或 P8 限制；展開見實際收藏、主要／支援關聯的解說、能力、理由及推論限制。
5. 其他片段方向與待題目課程保留，不消失；來源連結開原課程詳情，不把建議課程混入判讀依據。
6. 收藏變動時收起舊結果並提示重新查看，不自動生成新角色；跨分頁同樣處理。若載入途中變動，拒絕呈現過時結果。原結果不另存 localStorage，重新載入需主動查看。
7. 課程資料無法讀取時仍可看角色依據中的課名與理由，但不提供失效的詳情按鈕；資料／角色讀取失敗彼此獨立。

## 資料來源與取捨

`../role-rules-20261011/build-public-data.mjs` 從經驗證的本機資料契約衍生公開 JSON；只包含學系轉譯與課程規劃，不讀取私有研究資料。使用生成物而非在瀏覽器解析 Markdown，代價是來源更新後須重建；`--check` 可攔截過期生成物。

首次主動操作才載入角色資料，避免找課者支付額外資料成本。過時結果直接收起，代價是無法與舊結果並排比較，但避免引用已移除課程。詳情較長採按需展開，重要限制仍可見。沒有轉場時間參數，新增動效為 0ms 直接狀態切換。

## 檢查方式

- 本機 28 項判讀測試、原 69 課結構檢查、生成物新鮮度檢查。
- 瀏覽器核對四種狀態、八方向、實際課程依據、按需載入、錯誤／格式失敗／慢請求後更新、重試、來源詳情與鍵盤返回。
- 收藏取消、清空、其他分頁更新後舊角色收起，不殘留移除課程、不自動更新；原首頁／找課／收藏回歸。
- 320、390、700、768、900、1024、1440px 無整頁橫向溢出；手機按鈕、長課名、展開內容及多方向均檢查。另檢視 200% 文字放大與減少動態。
- 僅自動化 Chrome 模擬及截圖檢視；未實體手機、Safari、讀屏或高中生測試，不宣稱完整無障礙或教育效度驗證。
