# 四大公會建築設計 brief｜第一輪

## 目的

將首頁原本以人物代表的四大領域，重構成四個可進入的「公會」。

- 第一層是公會／學習領域：以建築、名稱與一句探索提問呈現。
- 第二層是專業人物：八位獨立人物維持為可探索的方向。
- 原本四位領域人物保留為各公會門前的引導者；畫面與文字不再將其稱為領域名稱或與八位專業人物並列。

此文件只定義視覺與生成方向。尚不生成素材、不替換頁面、不改動 69 門課程資料。

## 第一輪驗收目標

1. 首次觀看者在 3 秒內能辨認四個是「可進入的公會」，而八個是「人物方向」。
2. 移除人物與文字後，每一棟建築仍能憑輪廓與招牌結構辨識所屬公會。
3. 每座建築是獨立、完整且可去背的單一資產；不依賴天空、地平線、群眾或相鄰建築才成立。
4. 建築與既有人物保有同一世界：溫暖紙感、手作材質、立體微縮模型般的動畫感、可見的生活痕跡；避免寫實遊戲截圖或冷硬科幻。
5. 建築比引導者更有視覺重量；引導者是「在此迎接你的人」，不是另一個領域標誌。

## 共用構圖與資產規格

### 結構

- 每張資產只含一座公會建築，正面略偏三分之四視角，完整看得見屋頂、入口與基座。
- 建築採垂直構圖，建議透明畫布 `1200 × 1500px`；建築本體約占畫布高度 82–88%，四周保留 6–9% 安全邊界。
- 預留入口前方平坦空間，讓既有引導者以獨立透明 WebP 疊在建築前方；人物高度約為建築高度的 30–38%。
- 建築底部可有極薄的石座、階梯或懸浮平台，不能有延伸至畫布邊緣的地景。輸出需真正透明背景，不以米白背景模擬。

### 視覺共同語言

- 使用溫暖、略有顆粒與刷痕的 3D 手作動畫質感；比例可略誇張、屋頂和入口具有童話式戲劇性。
- 可用木、石、陶、布旗、黃銅、彩繪玻璃、紙張、發光礦石等有觸感的材料；細節要像長年有人使用、修補與留下記號。
- 允許魔幻寫實，但魔法應服務於知識、故事、製作或連結，不能成為通用的漂浮粒子裝飾。
- 光線為柔和的側前方日光與少量室內暖光；不採全黑背景、強紫藍霓虹、鏡面金屬、軍事城堡或歐洲中世紀制式城門。
- 四座建築需要共享同一材質密度、攝影角度和人物世界比例，但不可套同一座房子的換色版本。

### 首頁層級規則

- 卡片主標只顯示公會名稱；原四位人物的名稱不在卡片標題、快速選取或段落標題出現。
- 領域的學習說明仍可保留，但改用公會的探索語氣，不使建築看起來像純裝飾。
- 八個專業人物區需有明顯區段標題，例如「探索你的專業方向」；四公會區則標示為「從一座公會開始探索」。
- 公會選取時以建築、名稱與入口狀態產生回饋；人物不獨立成為可與八角色相同的選項。

## 四座建築

### 01｜求是議會

**對應領域**：人文思維與方法
**現有引導者資產**：`觀察家.webp`（僅供版面疊放；不作 UI 名稱）
**核心問題**：我們如何提出問題、閱讀材料並理解不同觀點？

**建築原型**：一座向上生長的議會檔案館與觀測塔。底部是拱形石砌檔案庫，中段有可看見書頁、標記與標本抽屜的窗格，屋頂是偏心的觀測圓頂與一支指向遠方的黃銅望鏡。入口不是威嚴的封閉大門，而是幾層可慢慢走進去的階梯與半開的圓拱門。

**故事線索**：外牆嵌著小型問題牌、被風翻起的索引卡、不同高度的窺視窗；屋頂有一束溫暖光落在望鏡與桌上的紙張。它暗示「找問題、查線索、比對觀點」，而不是博物館式收藏。

**識別輪廓**：不對稱的圓頂＋長望鏡＋層層階梯。即使縮小，也要先看到向上求索的輪廓。

**色彩與材質**：苔綠、舊象牙白、沉靜藍灰、黃銅小件；石材可有手寫刻痕與草本色的窗邊植栽。

**人物站位**：引導者站在最下層階梯左前方，視線略朝入口與望鏡方向；不可遮住入口、望鏡或建築名稱預留區。

**避免**：學校校舍、法院、純圖書館立面、天文台寫實儀器、黑暗學院風、過度神祕的魔法塔。

### 02｜故事聖殿

**對應領域**：敘事與內容創作
**現有引導者資產**：`說書人.webp`（僅供版面疊放；不作 UI 名稱）
**核心問題**：你的故事可以如何被寫下、演出與傳播？

**建築原型**：一座由劇場、故事書庫與紙頁屋頂組成的聖殿。主體像一冊半開的巨書形成雙翼屋頂，中間是溫暖的舞台入口；高處有圓形彩繪玻璃窗，兩側以垂落的布幔、紙燈與小陽台表現不同媒介的敘事。

**故事線索**：入口旁有可翻轉的節目牌、從窗內露出的書脊與捲軸、懸在空中的紙燈；一張小小的空白海報暗示「下一個故事還沒被寫下」。所有細節應讓人感覺內容正在被寫、被說、被看見。

**識別輪廓**：展開書頁般的雙翼屋頂＋中央舞台拱門＋圓形花窗。縮小時應像一座正在張開的故事書。

**色彩與材質**：暖陶紅、杏橘、羊皮紙米色、墨綠與琥珀光；布幔、紙張、木雕與彩色玻璃要有可辨觸感。

**人物站位**：引導者立於入口前偏右、靠近節目牌處，姿態像剛邀請人進場；舞台拱門與花窗必須完整可見。

**避免**：宗教崇拜符號、教堂複製品、只有圖書館書架、電影戲院招牌、童話城堡或單純巨大書本。

### 03｜數位天宮

**對應領域**：數位人文
**現有引導者資產**：`解碼師.webp`（僅供版面疊放；不作 UI 名稱）
**核心問題**：當人文材料遇上數位工具，能發現與做出什麼？

**建築原型**：一座由資料工坊、編碼塔與展示平台拼接而成的數位天宮。建築不應是摩天大樓，而像由匠人逐步向上打造的垂直殿閣：齒輪驅動的升降台、模組化窗格、露出的資料線路，以及用藍綠光讀取圖樣的中央工作台。

**故事線索**：透明窗內可見打孔紙帶、圖像標註板、發光的地圖碎片與小型機械手；屋頂以像素化屋瓦或摺疊面板暗示轉譯。技術細節要能看出「整理、解碼、製作、呈現」，也要仍然有人文材料的溫度。

**識別輪廓**：層疊向上的殿閣式工坊塔＋外露齒輪／軌道＋藍綠發光的中央窗。縮小時看得出是一座正在運作的數位天宮。

**色彩與材質**：靛藍、青綠、霧灰、暖木色與少量黃銅；光源是工具與資料發亮，不使用大量霓虹。

**人物站位**：引導者站在前方右側的小型操作平台，與中央工作台形成視線關係；不能遮住外露機構與發光主窗。

**避免**：賽博龐克街景、玻璃帷幕科技總部、機器人城市、只有電路板貼圖、冷白實驗室或侵略性武器機械。

### 04｜萬象聯盟

**對應領域**：文化創意與社會設計
**現有引導者資產**：`設計師.webp`（僅供版面疊放；不作 UI 名稱）
**核心問題**：如何將地方、人的需求與創意，變成可共同實踐的提案？

**建築原型**：一座多入口、多材質相連的聯盟會所。核心是圓形公共廳，周圍伸出如橋、棚架、工作坊與小花園般的構件；它不追求左右絕對對稱，而要像來自不同社群的部分逐漸被接在一起，最終形成可聚集、可製作、可討論的場所。

**故事線索**：可見的共用長桌、公告旗、被修補的座椅、地方圖樣磁磚、雨水收集槽與小型展示架；入口可有兩條不同的路匯入一個圓形廣場。細節應帶出合作、地方觀察、試作與長期照顧。

**識別輪廓**：中央圓廳＋兩至三條匯入的橋／棚架＋高低不同的布旗與屋頂。縮小時要能看出「許多路走向同一處」。

**色彩與材質**：陶土橘、磚紅、鼠尾草綠、木色、米白與少量靛藍織布；可以有陶磚、回收木料、布旗與植栽，但不是市集攤位。

**人物站位**：引導者站在中央入口前偏左，面向匯入的路徑；保留圓廳、橋梁交會與公共長桌等核心敘事元素。

**避免**：企業總部、單一豪華博物館、只有商店街、純農村小屋、貧困化的社區意象，或把「多元」畫成雜亂拼貼。

## 生成與審稿順序

1. 先生成「求是議會」單棟建築，連同既有 `觀察家.webp` 做一次首頁疊放測試。
2. 檢視在桌面、390px 手機版與縮圖時，公會／人物／八專業角色是否仍可快速分層。
3. 確認其材質、鏡頭與視覺重量後，再生成其餘三座；四座須作為同一組資產共同審稿。
4. 使用者確認建築與既有人物站位後，才修改首頁名稱、文案、元件結構及資產載入。

## 第一輪決策點

- 公會名稱是否使用目前四個名稱並依本文件順序對應原四領域？
- 「聖殿」是否保留；其建築將使用文化與故事儀式感，但排除任何特定宗教符號。
- 人物是否只作靜態前景引導，或仍可點選來觸發同一個公會資訊？建議後者，保留可用性但讓按鈕與標題只指向公會。
