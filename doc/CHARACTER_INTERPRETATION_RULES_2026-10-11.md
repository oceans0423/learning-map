# 探索角色判讀流程與收藏情境推演｜V0.1

日期：2026-10-11。狀態：判讀規則提案與人工情境推演，尚未實作演算法或網站畫面。

## 1. 本輪承接與假設

使用者已接受前版原則：看互補能力，不按收藏數量排名；角色與收藏自願；不設最低門數、權重或百分比；一般表達、資料整理及地方觀察不能擴張成教學、分析或共創。

本版依據 `CHARACTER_COURSE_ABILITY_MAPPING_2026-10-11.md` 的 84 筆關聯及推論限制。角色關聯屬已整理的內容規劃，不是課綱逐筆證實或心理測量。新提出的是下列判讀流程、結果狀態與情境預期，不能把使用者對原則的接受當成本版測試預期已全部核可。

使用 UX Architect 分開「資料來源」「解釋規則」「結果狀態」，避免把呈現順序當成配對分數。不改 UI，因此本輪不指定布局、色彩、互動動效參數；後續畫面仍須依 `ui-design/` 討論。

## 2. 比較的單位：有依據的工作方式

不問哪個角色關聯課最多，而問：能否從實際收藏說出此角色的核心工作方式，且沒有跨越課程限制？

每個候選方向要留下：

1. 收藏課程 ID，以及本課對此角色的關聯。
2. 直接呈現角色工作方式的「代表」線索。
3. 該角色的互補面向，以及各面向由哪門課、哪項能力支持。
4. 已知缺口／限制；支援課只能補充，不能以數量替代代表線索。

同一門課可支持數個面向，不要求不同面向一定由不同課供給。單課若已直接連結相關面向，也可呈現一個暫定探索方向；不偷渡「至少兩門／三門」門檻。收藏很多同類課則增加可說明的材料，不代表能力更強或必須贏過其他角色。

### 各方向要能說明的面向

這是本版建議的定性判準，未轉成程式條件或數值。對應時須使用逐課子面向及限制，不只看 H 標籤。

| 角色 | 必須能說明的工作方式 | 不足以單獨成立的線索 |
| --- | --- | --- |
| P1 探索者 | 問題／解釋意圖與文本或田野材料相互連結 | 人文概論、文化背景知識的堆疊 |
| P2 創作人 | 材料／主題如何轉為有表達意圖的作品 | 只閱讀作品，未連結創作或媒介表達 |
| P3 引路人 | 內容理解如何轉為面向讀者的說明，或面向學習者的引導 | 一般語文表達；不要求出版與教學兩路皆具備 |
| P4 分析師 | 資料操作與分析解讀如何回應人文問題 | 數據整理、數位展示或一般文本細讀 |
| P5 策展人 | 文化／敘事內容如何透過觀看或參與流程形成體驗 | 漂亮的數位呈現或單純主題介紹 |
| P6 造物者 | 人的需求如何連結工具、可測試方案與檢查修訂 | 只有科技思辨，或只有不明用途的工具操作 |
| P7 策略師 | 文化內容如何連結對象／目標、資源或傳播方案 | 只有創意作品或文化轉譯，未見方案安排 |
| P8 開拓者 | 地方／社群理解如何連結共同目標與實踐方向 | 只有田野、永續閱讀或一般專題分工 |

P8 只能先表述「地方與社會實踐的探索方向」；目前資料不足以把共同目標擴張為「已具共同決策與執行訓練」。P4、P6 亦須保留課綱尚未核對的分析流程與實作深度限制。這是內容依據的邊界，不是學生不足。

## 3. 決策順序與結果狀態

1. 只採當下有效收藏，去重；移除課程即移除其依據。未知 ID 不參與判讀，不擅自改寫原收藏。
2. 逐一查看八角色的代表、支援關聯與限制；不使用瀏覽時間、點擊頻率、性別或其他人格推測。
3. 區分「能說明工作方式的候選方向」與「只有片段線索的方向」。後者可供探索，但不靠支援課數量升級成候選。
4. 依候選方向的情況顯示下表狀態。不要求選出唯一贏家，不用跨域數或課數決勝。
5. 原因只列實際收藏中的課程；建議補充課程另列，不能混入形成結果的證據。

| 狀態 | 何時使用 | 學生可讀說法 |
| --- | --- | --- |
| 單一方向 | 一個方向可清楚說明工作方式，其他僅有支援或片段線索 | 「目前的收藏呈現○○的探索方向。」 |
| 雙方向 | 兩個方向各自有可說明的工作方式；共享課程也可，但理由必須不同 | 「你的收藏連結了○○與○○，分別著重……。」 |
| 多元方向 | 三個以上方向都有可說明的依據 | 「你的收藏涵蓋多種方向，可以分別查看。」 |
| 線索尚不足 | 沒有方向能說清核心工作方式，或只有待題目確認的課程 | 「目前可看見這些學習線索，還不急著配成角色。」 |

補上「多元方向」是本輪的新提案：不能因版面想放兩張圖，就任意丟掉第三個有效方向。所有狀態都能查看八角色、原收藏與能力依據，不設解鎖。多元方向也不要求學生另外回答問卷或放棄部分收藏。

單一、雙向與多元結果都只是當下興趣的解讀，沒有資格或完成度高低。單課結果要明示依據集中於一門課，不藉此要求多收藏；「線索尚不足」也不是學習能力不足。

### 變動與不變性檢查

- S10 移除 `course-031` 後：應留下 P1，不能殘留 P2 的敘事理由。
- S06 加入 `course-001`、`course-011`、`course-021`、`course-035` 後：仍是 P5 加人文基礎，不能因 P1 支援課多而跳成 P1。
- S05 調換輸入順序，或重複加入同一 ID：方向及依據不變；同集合與同規則版本須得到相同說明。
- 全部 69 門收藏：應能呈現八方向及各自限制，不能為了唯一主角任意決勝；三門待題目確認課不產生虛構關聯。
- 收藏增加可能真正形成新方向；收藏移除也可能使原方向變為片段。不能承諾角色永遠不變，但由使用者主動重新查看，不在瀏覽中頻繁切換。

## 5. 結果說明契約與取捨

未來結果至少保留：收藏快照、關聯版本、判讀規則版本、結果狀態、每個方向的來源課程／能力子面向／理由／限制，以及尚待題目確認的課程。方向列表不代表高低排名；內部若需穩定順序，可按 P1–P8 排列，必須明示是固定次序而非適配程度。

本版避免數值排名，代價是還需將自然語言子面向整理成一致、可查驗的標註，才能可靠程式化。不能用關鍵字搜尋或 H 標籤加總假裝已完成這一步，也不讓生成式模型每次隨意判角色。

本輪發現：

1. 單一／雙方向／不足三種狀態不夠，還需要多元方向。
2. 一門課可能已有清楚方向；最低收藏門數沒有必要。
3. 「兩門整理課」不會自動等於分析，但其中一門可能已清楚支持策展；需逐角色判讀，不能整組一律說不足。
4. P8 可先說地方與社會實踐方向，但實際共創深度尚不能由現有資料證明。

下一步：先檢視這些預期是否符合學系想傳達的方向，尤其 S09、S15、S18 與多元方向；再把關聯子面向資料化，建立可重現的本機判讀與反例測試，通過後才接入獨立樣張。這份文件不等於演算法已測試通過，正式網站及原課程檔均未修改。
