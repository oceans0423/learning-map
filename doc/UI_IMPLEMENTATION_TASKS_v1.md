## 2. 如何一項一項使用本文件

1. 依 UI-01 → UI-19 順序執行；先閱讀本任務與其依賴，不直接跳到星座特效。
2. 一次只開發一項；前一項的完成條件過關後再往下。每項結束都保持網站能啟動、原有資料可讀。
3. 狀態使用 `[ ] 待辦`、`[~] 進行中`、`[x] 已完成且驗證`、`[!] 阻擋`。文件寫好不等於程式完成。
4. 每項記錄修改檔案、實際執行檢查、瀏覽器證據、已知缺口；無瀏覽器或學生測試時寫「未驗證」，不能寫已通過。
5. 不清除既有工作、不全域格式化、不自動部署、不為此重建專案或加入大型動效依賴。
6. 本文件的元件名／新增資料路徑是建議邊界，**不是已確認存在的程式位置**。UI-01 先定位實際落點；結構查詢遵守專案 CodeGraph 規則。索引未初始化時詢問是否建立，不使用舊目錄索引；未獲答覆可繼續文件／資料檢查，不偷偷初始化。
7. UI-11 是找課主流程的工程關卡；工程關卡未通過，不以星座功能掩蓋問題。學生測試若無人可測，另列待測，不假裝通過，也不必停止所有選用模組開發。
8. UI-01～UI-11 完成後可先交付完整找課版本；UI-12～UI-19 完成後才交付含個人星座的版本。PNG、分享網址、多星座不在本輪。

## 4. 共用按鈕與動效契約

### 按鈕狀態

| 狀態 | 視覺／行為 | 不能做的事 |
| --- | --- | --- |
| normal | 可辨識的形狀、清楚動詞與命中區 | 看起來只有裝飾 |
| hover | 表面／輪廓輕亮，僅精準指標裝置使用 | 自動選課、偷換內容 |
| focus-visible | 獨立清楚焦點框；深色／暖紙各有對比 | 移除 outline 而無替代 |
| pressed | 立即短下壓或表面變化 | 移動命中區、延後資料更新 |
| selected | 持續輪廓／勾選＋正確語意 | 只有顏色或短暫動畫 |
| disabled | 明確不可操作，必要時說明原因 | 假裝可點、只依賴灰色 |
| loading | 真實非同步等待才出現；文字說明 | 本機收藏假等待 |
| success／error | 與實際結果一致的文字；錯誤提供出口 | 自動計時假成功、只用消失 toast |

### 動效起始設定

| 操作 | 起始時間 | 主要回饋 | reduced-motion |
| --- | --- | --- | --- |
| 按鈕按壓 | 100–150 ms | 表面／短下壓 | 即時表面變化 |
| 星點對焦 | 100–140 ms | 暖白輪廓 | 靜態輪廓 |
| 筆記／學期交接 | 180–240 ms | 短淡入、位置穩定 | 直接換內容 |
| 收藏 | 220–320 ms | 星點短程移至摘要 | 文字＋狀態 |
| 拖曳 | 指標即時跟手 | 合法位置、必要吸附 | 跟手保留，額外彈性關閉 |
| 首次命名完成 | 400–600 ms | 短畫線與名稱顯示 | 立即顯示結果 |

數值是原型起始值，不是已驗證「流暢」。先做好狀態與布局，再調速度。

每個互動都需確認六件事：

> 觸發 → 即時回饋 → 提交後狀態 → 取消／反向 → 鍵盤／觸控替代 → 減少動效。

共同限制：

- 不使用 `transition: all`；動畫優先局部 transform／opacity。
- 不等待動畫才提交收藏、選取或焦點；不讓動畫副本重複參與讀屏／點擊。
- 快速反向從當前視覺狀態接續；清理取消／卸載的動畫、capture、事件與副本。
- 不在每一幀交錯量測與修改布局；拖曳更新按 rAF 合併。
- 一般找課沒有永久漂浮、滾動視差、粒子或自定義游標。
